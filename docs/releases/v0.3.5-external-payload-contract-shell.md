# v0.3.5 — External Payload Contract Shell

## Summary

Adds `PolymarketMarketPayload` — a shell dataclass representing the external Polymarket API payload format, and `map_to_raw_payload_item()` — a mapping function that converts it to `RawPayloadItem`. No HTTP client, no real network calls. Establishes the external format boundary with explicit error handling and no silent fallback.

| File | Change |

| `backend/app/adapters/external_payload.py` | New — `ExternalPayloadMappingError`, `PolymarketMarketPayload`, `map_to_raw_payload_item()` |
| `backend/tests/adapters/test_external_payload.py` | New — 7 external payload tests |

## External Payload Contract

**`PolymarketMarketPayload`**
| Field | Maps to | Notes |
|-------|---------|-------|
| `condition_id` | `RawPayloadItem.market_id` | Polymarket condition identifier |
| `question` | `RawPayloadItem.title` | Market question text |
| `end_date` | `RawPayloadItem.timeframe` | Raw string — validated by normalization layer |

**`map_to_raw_payload_item()`**
- Strips whitespace from all fields
- Raises `ExternalPayloadMappingError` if any field is empty/whitespace-only
- No silent fallback
