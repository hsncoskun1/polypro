Introduces live order response classification and fill confirmation read model.
No live execution. No network calls. Clean seam for future exchange client integration.

## OrderResponseStatus Values

| Value | Trigger |
|-------|---------|
| `submitted` | Default — no acknowledgment yet |
| `accepted` | Exchange acknowledged |
| `partially_filled` | 0 < filled_size < requested_size |
| `filled` | filled_size >= requested_size |
| `rejected` | Exchange rejected |
| `retryable_failure` | Transient failure, retry possible |
| `terminal_failure` | Permanent failure, no retry |

## FillConfirmationStatus Values

| Value | Trigger |
|-------|---------|
| `not_confirmed` | filled_size == 0 |
| `partially_confirmed` | 0 < filled_size < requested_size |
| `fully_confirmed` | filled_size >= requested_size |
| `confirmation_failed` | terminal_failure |

## Classifier Priority (classify_order_response)

| Priority | Condition | Status |
|----------|-----------|--------|
| 1 | terminal_failure=True | TERMINAL_FAILURE |
| 2 | retryable=True | RETRYABLE_FAILURE |
| 3 | rejected=True | REJECTED |
| 4 | filled_size >= requested_size | FILLED |
| 5 | filled_size > 0 | PARTIALLY_FILLED |
| 6 | exchange_acknowledged=True | ACCEPTED |
| 7 | default | SUBMITTED |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Trigger/submitted/fill lifecycle NOT collapsed | Binding project decision |
| LiveOrderResponse and FillConfirmation are separate | Read model separation |
| remaining_size computed in classifier | Single source of truth |
| terminal_failure → CONFIRMATION_FAILED | No fill possible on terminal failure |
