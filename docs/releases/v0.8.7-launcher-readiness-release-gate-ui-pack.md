# Release Notes — v0.8.7 Launcher + Readiness + Release Gate UI Pack

**Version:** v0.8.7
**Branch:** feat/v0.8.7-launcher-readiness-release-gate-ui-pack
**Status:** In progress

## Summary

Full Launcher UI implementing the frontend readiness surface. Polls `/readiness`
endpoint, renders 5 readiness fields, release gate panel (release_ready and
live_applied_testing_ready shown separately), blocked reason messages, port info.
`live_applied_testing_ready` is never auto-enabled. Secrets never shown.
Turkish UI throughout. Backend `/readiness` endpoint added. Full test coverage.

## Invariants Enforced

- `live_applied_testing_ready` = False always (never auto-enabled)
- `launcher_blocked` = True when live gate not authorized
- `continue_destination` = None when blocked
- No secrets in `/readiness` response
- `release_ready` and `live_applied_testing_ready` always shown separately
