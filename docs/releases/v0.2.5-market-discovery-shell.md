# v0.2.5 — Market Discovery Shell

## Summary

Adds a clean, testable discovery layer foundation. `run_discovery()` processes a list of `DiscoveryItem` candidates against the in-memory registry and returns a `DiscoverySummary`. No HTTP, no scheduler, no background jobs — stub/static input only.

## Changes

| File | Change |
|------|--------|
| `backend/app/domain/markets/discovery.py` | New — `DiscoveryItem`, `DiscoverySummary`, `run_discovery()` |
| `backend/app/main.py` | Version bumped to 0.2.5 |
| `backend/tests/domain/test_market_discovery.py` | New — 5 discovery tests |

## Discovery Contract

**Input:** `list[DiscoveryItem]` — each item has `market_id`, `title`, `timeframe` (raw string)

**Output:** `DiscoverySummary`
| Field | Description |
|-------|-------------|
| `added_count` | Markets successfully added to registry |
| `skipped_duplicate_count` | Items already in registry |
| `skipped_invalid_count` | Items with invalid timeframe |
| `total_seen` | Total items processed |
