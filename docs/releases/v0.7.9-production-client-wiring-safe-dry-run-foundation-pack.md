# v0.7.9 — Production Client Wiring + Safe Dry-Run Foundation Pack

## Summary

Introduces production client wiring and safe dry-run foundation: client mode enum,
wiring context, wiring result, dry-run result, adapter factory, and client selection
evaluator. Four client modes are supported. Dry-run and simulation modes never
perform real outbound. No production exchange client implemented yet — seam only.

## Client Modes

| Mode | Client Ready | Real Outbound | Dry-Run Active |
|------|-------------|---------------|----------------|
| SIMULATION_MOCK | Always | Never | No |
| LIVE_MOCK | Always | Never | No |
| LIVE_DRY_RUN | If wiring ready | Never | Yes |
| LIVE_PRODUCTION | If all guards pass | Yes (if all clear) | No |

## Production Guard Priority (LIVE_PRODUCTION)

| Priority | Condition | Blocker |
|----------|-----------|---------|
| 1 | outbound_execution_enabled=False | real_outbound_disabled |
| 2 | production_client_selected=False | production_client_not_selected |
| 3 | production_wiring_ready=False | production_wiring_incomplete |
| 4 | All clear | ready |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Dry-run real_outbound_performed=False always | Structural guarantee — not a runtime check |
| All blockers collected (no short-circuit) | Consistent with v0.7.2 pattern |
| Factory raises ValueError for LIVE_PRODUCTION without client | Explicit — no silent fallback |
| Mock adapter returned for all non-production modes | Clean test surface |
