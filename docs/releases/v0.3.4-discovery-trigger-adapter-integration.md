# v0.3.4 — Discovery Trigger Adapter Integration

## Summary

Wires `PayloadDiscoveryAdapter` into the `POST /api/v1/discovery/trigger` endpoint. The endpoint now routes request items through `RawPayloadItem` → `PayloadDiscoveryAdapter` → `run_discovery_service()`. `StubRawDiscoverySource` and direct `RawMarketItem` construction are removed from the endpoint. No new files, no behavior change — adapter seam is now the live path.

## Changes

| File | Change |
|------|--------|
| `backend/app/api/discovery.py` | Updated — `StubRawDiscoverySource`/`RawMarketItem` replaced with `PayloadDiscoveryAdapter`/`RawPayloadItem` |

## Before / After

**Before (v0.3.1–v0.3.3):**
```
trigger endpoint → StubRawDiscoverySource(RawMarketItem list) → run_discovery_service()
```

**After (v0.3.4):**
```
trigger endpoint → RawPayloadItem list → PayloadDiscoveryAdapter → run_discovery_service()
```
