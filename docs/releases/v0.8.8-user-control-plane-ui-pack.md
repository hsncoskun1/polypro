# Release Notes — v0.8.8 User Control Plane UI Pack

**Version:** v0.8.8
**Branch:** feat/v0.8.8-user-control-plane-ui-pack
**Status:** In progress

## Summary

User control plane UI surface. Real user dashboard connecting to `GET /control-plane`
endpoint. Positions (open/closed), PnL cards, balance cards, claim summary, live gate
status — all in Türkçe. Admin panel not included. Live testing not included.
