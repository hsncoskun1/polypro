# v0.3.3 — Discovery Source Adapter Shell

## Summary

Adds `PayloadDiscoveryAdapter` — a small adapter shell that implements the `RawDiscoverySource` contract. Accepts a list of `RawPayloadItem` objects and maps them to `RawMarketItem` for the pipeline. No HTTP client, no real external source, no auth, no scheduler. Establishes the seam point for future Polymarket API integration.

## Adapter Contract

**`PayloadDiscoveryAdapter`**
- Input: `list[RawPayloadItem]` — raw external payload format (placeholder for future Polymarket fields)
- Output: `list[RawMarketItem]` via `.fetch()` — satisfies `RawDiscoverySource` protocol
- Plugs directly into `run_pipeline()`, `run_discovery_service()`, and the trigger endpoint unchanged
