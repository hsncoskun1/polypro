# v0.2.9 — Market Discovery Pipeline Hardening

## Summary

Hardens the v0.2.8 pipeline shell before real source integration. `run_pipeline()` now raises `TypeError` if `source.fetch()` returns a non-list — explicit failure, no silent fallback. Four new edge-case tests cover bad source output, total_seen invariant, and whitespace-only field handling. No new features, no contract breaks.

## Changes

| File | Change |
|------|--------|
| `backend/app/domain/markets/pipeline.py` | Modified — fetch result type validation added to `run_pipeline()` |
| `backend/tests/domain/test_market_pipeline.py` | Modified — 4 new edge-case tests added |
| `backend/app/main.py` | Version bumped to 0.2.9 |

## Hardening Details

**`run_pipeline()` — fetch result validation:**
- Calls `source.fetch()`, stores result
- If result is not a `list`, raises `TypeError` with explicit message
- Prevents silent undefined behavior if a source implementation returns `None`, a string, or any other non-list

**New test coverage:**
| Test | What it hardens |
|------|----------------|
| `test_source_returning_none_raises_type_error` | fetch() → None is caught explicitly |
| `test_source_returning_non_list_raises_type_error` | fetch() → str/other is caught explicitly |
| `test_total_seen_always_equals_raw_input_count` | added + skipped_duplicate + skipped_invalid == total_seen invariant |
| `test_whitespace_only_fields_counted_as_invalid` | whitespace-only market_id/title/timeframe → skipped_invalid |
