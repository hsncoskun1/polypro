# Release Notes — v1.0.9 Admin Entitlement Save Flow + User Visibility Enforcement Pack

## Summary

Admin entitlement save/cancel/error flow completed. User panel now enforces
entitlement: visible_panels, trading_enabled, blocked_reason_messages.

## Changes

**Frontend — Admin:**
- `EntitlementEditor`: real save error handling (saveError state, shown inline);
  blocked_reason_messages textarea field added; cancel resets local state to
  original entitlement before closing; onSave returns { ok, error } contract
- `AdminPanel`: handleSave returns { ok, error } from updateEntitlement;
  null response = save failure surfaced to editor

**Frontend — User:**
- `UserPanel`: uses useEntitlement hook; trading lock shown when trading_enabled=false
  with blocked_reason_messages; visible_panels enforces panel visibility
  (empty = show all; non-empty = only listed panels shown)

**Tests:**
- `entitlement-visibility.test.tsx`: 13 new tests covering editor save/cancel/error,
  trading lock, blocked reasons, panel visibility enforcement

## Test Results

- Backend: 1638 passed, 1 skipped
- Frontend: 190 passed (177 existing + 13 new)
- 0 regressions
