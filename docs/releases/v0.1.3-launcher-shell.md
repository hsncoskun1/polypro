# Release Note — v0.1.3 Launcher Shell

## Purpose
Provide a single-command launcher that starts backend and frontend, polls backend health, and opens the browser.

## What Was Done
- Created `launcher/src/launcher.py` — subprocess orchestration
  - `start_backend()` — launches uvicorn via venv python
  - `start_frontend()` — launches `npm run dev`
  - `wait_for_health()` — polls `/health` with timeout
  - `open_browser()` — opens frontend URL
  - `terminate()` — graceful shutdown with force-kill fallback
  - `run()` — main orchestration entrypoint
- `launcher/requirements.txt` — pytest dependency
- `launcher/tests/test_launcher.py` — 5 unit tests
