# v0.2.6 — Market Discovery Source Contract Shell

## Summary

Adds a clean, pluggable source contract layer for the discovery domain. `DiscoverySource` defines the input protocol. `StubDiscoverySource` provides a static in-memory implementation. `run_discovery_from_source()` wires the contract to the existing discovery shell — no real HTTP, no scheduler, no auth.

## Source Contract

**`DiscoverySource` (Protocol)**
- Single method: `fetch() -> list[DiscoveryItem]`
- Real sources (e.g. Polymarket adapter) implement this contract in future versions

**`StubDiscoverySource`**
- Wraps a static `list[DiscoveryItem]`
- Used for testing and shell development; no external calls

**`run_discovery_from_source(source, registry)`**
- Delegates to `run_discovery(source.fetch(), registry)`
- No new discovery logic — existing shell behavior preserved exactly
