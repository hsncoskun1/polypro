# v0.7.0 — Live Readiness Foundation Pack

## Summary

Introduces live mode protection foundation: mode enum, readiness context/result contracts, and a sequential-gate evaluator.
Simulation default remains — no live execution, no live API wiring.
Live mode requires explicit opt-in and full credentials before live_ready=True.

## LiveReadinessContext Fields

| Field | Description |
|-------|-------------|
| `simulation_mode_default` | True when system is in simulation-default state |
| `live_mode_requested` | True when live mode has been explicitly requested |
| `live_mode_enabled` | True when live mode is currently enabled |
| `explicit_live_enable` | True when operator has consciously activated live mode |
| `wallet_address_present` | Wallet address configured |
| `private_key_present` | Private key configured |
| `funder_address_present` | Funder address configured |

| `api_passphrase_present` | Exchange API passphrase configured |

## LiveReadinessResult Fields

| Field | Description |
|-------|-------------|
| `live_ready` | True only when all gates pass and no credential blockers |
| `blocker_reasons` | List of all active blocker reason codes |

## Evaluator Gate Model

| Gate | Condition | Result |
|------|-----------|--------|
| Gate 1 | simulation_mode_default=True AND live_mode_requested=False | live_ready=False, blocker_reasons=[] |
| Gate 2 | explicit_live_enable=False | live_ready=False, blocker_reasons=["explicit_live_enable_required"] |
| Gate 3 | credential checks (all run, no short-circuit) | live_ready=(no blockers), blocker_reasons=[all missing] |

## Blocker Reason Codes

| Reason | Trigger |
|--------|---------|
| `explicit_live_enable_required` | explicit_live_enable is False (Gate 2) |
| `wallet_address_missing` | wallet_address_present is False |
| `api_key_missing` | api_key_present is False |
| `api_secret_missing` | api_secret_present is False |
| `api_passphrase_missing` | api_passphrase_present is False |
| `private_key_missing` | private_key_present is False |
| `funder_address_missing` | funder_address_present is False |
| `relayer_api_missing` | relayer_api_present is False |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Simulation default = not live_ready, no blockers | Not a failure state — default operating mode |
| Gate 2 returns single blocker, stops | Credentials irrelevant until explicit enable is set |
| Credential checks all run (no short-circuit) | Operator needs full visibility into missing items |
| live_ready = len(blockers) == 0 | Single truth source |
