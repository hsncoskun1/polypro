# v1.0.0 — Polymarket HTTP Client Pack

## Scope

In this version: PolymarketHttpClient foundation, httpx-based HTTP transport layer, HMAC auth integration seam, fail-closed error classification.
Not in this version: balance fetch, fill stream, live order execution.

## Summary

v1.0.0 establishes the HTTP client foundation for all live Polymarket API communication. PolymarketHttpClient wraps httpx with fail-closed error handling and integrates with PolymarketRequestSigner for HMAC Level 2 authentication.

## New Files

### `backend/app/domain/live/polymarket_http_client.py`
httpx-based HTTP client for Polymarket CLOB API. Foundation layer:
- HMAC auth header injection via PolymarketRequestSigner
- Fail-closed HTTP error classification
- retryable / terminal_failure on all error paths
- No silent fallback

## Fail-Closed Guarantees

- Auth errors → terminal_failure
- Timeout / 5xx / 429 → retryable
- Unknown errors → terminal_failure (fail-closed)
