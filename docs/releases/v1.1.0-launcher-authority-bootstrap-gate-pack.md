# v1.1.0 — Launcher Authority + Bootstrap Gate Pack

## Summary

Adds launcher authority enforcement: the launcher now generates a cryptographic grant token, passes it to the backend via environment variable, and operational API routes are gated behind this token when `REQUIRE_LAUNCHER_GRANT=true`.

## Changes

### Backend
- `app/core/config.py` — Added `LAUNCHER_GRANT_TOKEN` and `REQUIRE_LAUNCHER_GRANT` config vars
- `app/api/launcher.py` — New `GET /api/v1/launcher/status` endpoint (always open, no auth)
- `app/api/deps.py` — Added `require_launcher_grant()` FastAPI dependency
- `app/main.py` — Registered `launcher_router`; applied `require_launcher_grant` dependency to `control_plane`, `admin_control_plane`, `admin_users`, `user_entitlement` routers
- `tests/api/test_launcher_api.py` — 8 new tests for launcher status endpoint and gate behavior

### Launcher
- `launcher/src/launcher.py` — Generates `LAUNCHER_GRANT_TOKEN = secrets.token_hex(32)` before starting backend; passes it in subprocess env

### Frontend
- `src/hooks/useLauncherStatus.ts` — New hook: fetches `/api/v1/launcher/status`
- `src/routes/Launcher.tsx` — Shows `launcher-grant-gate` banner if `grant_required=true` and `launched=false`
- `src/test/launcher.test.tsx` — 6 new launcher grant gate tests
