# v0.2.4 — Market Registry Persistence Hardening

## Summary

Hardens the SQLite persistence layer against corrupt data and missing directories. No new dependencies, no API changes.

## Changes

| File | Change |
|------|--------|
| `backend/app/persistence/markets.py` | `load()` skips corrupt rows with warning log; `save()` adds `mkdir` safety |
| `backend/app/main.py` | Version bumped to 0.2.4 |
| `backend/tests/persistence/test_market_store.py` | 2 new hardening tests added |

## Hardening Details

| Scenario | Behavior |
|----------|----------|
| Row with invalid enum value in DB | Logged as warning, row skipped, valid rows returned |
| Parent directory missing when `save()` is called | Directory re-created automatically |
