# v0.2.4 — Market Registry Persistence Hardening

## Summary

Hardens the SQLite persistence layer with explicit failure on corrupt data and path safety on save. No new dependencies, no API changes.

## Changes

| File | Change |
|------|--------|
| `backend/app/persistence/markets.py` | `load()` raises explicit `ValueError` with context on corrupt row; `save()` adds `mkdir` safety |
| `backend/app/main.py` | Version bumped to 0.2.4 |
| `backend/tests/persistence/test_market_store.py` | 3 new hardening tests (2 explicit error cases + 1 dir recreate) |

## Hardening Details

| Scenario | Behavior |
|----------|----------|
| Row with invalid timeframe in DB | `ValueError` raised with message including `market_id` and bad value |
| Row with invalid status in DB | `ValueError` raised with message including `market_id` and bad value |
| Parent directory missing when `save()` is called | Directory re-created automatically |
