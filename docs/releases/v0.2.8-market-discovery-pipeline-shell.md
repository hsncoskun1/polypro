# v0.2.8 — Market Discovery Pipeline Shell

## Summary

Wires the three discovery layers into a single pipeline entry point. `RawDiscoverySource` defines the raw input protocol. `StubRawDiscoverySource` provides a static implementation. `run_pipeline()` chains source → normalize → discover in one call, returning a unified `DiscoverySummary`. No HTTP, no scheduler, no auth — stub/static flow only.

## Pipeline Contract

**Input:** `RawDiscoverySource` — provides `fetch() -> list[RawMarketItem]`

**Flow:** `source.fetch()` → `run_discovery_from_raw()` (normalize + discover) → `DiscoverySummary`

**Output:** `DiscoverySummary`
| Field | Description |
|-------|-------------|
| `added_count` | Markets successfully added to registry |
| `skipped_duplicate_count` | Items already in registry |
| `skipped_invalid_count` | Normalization failures + invalid timeframe errors |
| `total_seen` | Total raw items from source |

- `source.py` (`DiscoverySource`, `StubDiscoverySource`) — unchanged
- `normalize.py` (`RawMarketItem`, `normalize_item`, `run_discovery_from_raw`) — unchanged
