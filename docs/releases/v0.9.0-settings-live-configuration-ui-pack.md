# Release Notes — v0.9.0 Settings + Live Configuration UI Pack

**Version:** v0.9.0
**Branch:** feat/v0.9.0-settings-live-configuration-ui-pack
**Status:** In progress

## Summary

Settings and live configuration UI surface. Connects to `GET /settings` endpoint.
Credential configured status (masked — no plaintext values), live configuration state,
trading configuration, release gate visibility — all in Türkçe. No credential values
are ever shown. User/admin panels untouched.

## Invariants Enforced

- Credential values NEVER in response — only configured/not-configured boolean
- `live_applied_testing_ready` = False — never auto-enabled
- `masked_secret_fields` shows which fields are configured, not values
- Secrets never shown in UI — only status flags
- User/admin panels untouched
