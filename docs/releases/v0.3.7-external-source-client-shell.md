# v0.3.7 — External Source Client Shell

## Summary

Adds `PolymarketClient` — a minimal HTTP client shell for fetching raw market data from a URL. Uses `httpx`. Returns parsed `list[dict]`. Raises `PolymarketClientError` on any failure (timeout, HTTP error, JSON parse failure, non-list response). No auth, no retry, no backoff. Not wired to the discovery pipeline.

## Client Contract

**`PolymarketClient(url, timeout=10.0)`**
| Method | Returns | Raises |
|--------|---------|--------|
| `fetch()` | `list[dict]` | `PolymarketClientError` on timeout, HTTP error, JSON failure, non-list |

**Error cases covered:**
- `httpx.TimeoutException` → `PolymarketClientError("Request timed out: ...")`
- `httpx.RequestError` → `PolymarketClientError("Request failed: ...")`
- HTTP status != 200 → `PolymarketClientError("HTTP {status} from ...")`
- JSON parse failure → `PolymarketClientError("Failed to parse JSON response: ...")`
- Non-list JSON → `PolymarketClientError("Expected JSON list, got ...")`

## Design Decisions

- Uses `httpx` (already in requirements) — no new dependency
- stdlib `unittest.mock` for test isolation — no `respx` or additional test lib
- Empty list `[]` is a valid response — caller decides how to handle it
- Shell only — not wired to trigger/service/adapter chain
