# v0.7.8 — Live Exchange Client Adapter Foundation Pack

## Summary

Introduces live exchange client adapter foundation: outcome status enum, request/response
contracts for submit/cancel/replace, order update model, abstract client interface, and
configurable mock stub. Business logic and orchestrator never access exchange details directly.
No real network calls. Seam only.

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| ABC interface | Forces contract compliance — real and mock clients implement same surface |
| Outcome status enum (7 values) | Clean, typed result — no raw exchange strings in business logic |
| Mock stub configurable per operation | Tests all outcome paths without network calls |
| cancel and replace are separate adapter methods | Consistent with v0.7.5 separate lifecycle intent |
| No network calls | Seam only — ready for real Polymarket client in future version |
