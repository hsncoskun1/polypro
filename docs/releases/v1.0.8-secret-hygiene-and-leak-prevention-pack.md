# Release Notes — v1.0.8 Secret Hygiene and Leak Prevention Pack

## Summary

Security hygiene and repo cleanup release. No new product features.

## Changes

- `.gitignore` hardened: added `*.sqlite`, `*.sqlite3`, `*.secret`, `secrets.*`,
  `credentials.*`, `logs/`, `*.log`, `*.pem`, `*.key`, `*.p12`, `*.pfx`, `*.crt`,
  `*.cer`, `launcher/data/`
- `LiveCredentials.__repr__` and `__str__` overridden — prevents credential values
  appearing in logs, tracebacks, or debug output
- `forgot-password` endpoint security comment strengthened — explicit production warning
- `.env.example` created — safe template for environment configuration
