# v0.6.0 — Risk Engine Pack

## Summary

Introduces hard risk block evaluation across six constraint dimensions.
All checks run — multiple blockers collected and returned together.
Daily loss cap, daily trade cap, per-event position limit, concurrent position limit, position size min/max.
risk_allowed = True only when all constraints are satisfied.
No frontend, no launcher, no sizing changes, no claim logic.

## RiskContext Fields

| Field | Description |
|-------|-------------|
| `daily_loss_limit` | Maximum allowable cumulative loss per day |
| `current_daily_loss` | Cumulative loss today (positive = loss incurred) |
| `daily_trade_cap` | Maximum number of trades allowed per day |
| `current_daily_trade_count` | Trades executed today |
| `event_limit` | Maximum open positions per market event |
| `current_event_open_positions` | Current open positions for this event |
| `max_concurrent_positions` | Maximum total open positions at any time |
| `current_open_positions` | Current total open positions |
| `min_position_size` | Minimum allowed position size |
| `max_position_size` | Maximum allowed position size |
| `requested_position_size` | Requested size for the proposed trade |

## RiskResult Fields

| Field | Description |
|-------|-------------|
| `risk_allowed` | True only when blocker_reasons is empty |
| `blocker_reasons` | List of all active blocker reason codes |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| All checks run (no short-circuit) | Operator needs full visibility into all active blockers |
| risk_allowed = len(blockers) == 0 | Single truth — no partial allow |
| At-limit = blocked (>=) | Reaching the limit means the limit is exhausted |
| blocker_reasons is a list | Multiple violations can coexist and must all be reported |

## Blocker Reason Codes

| Reason | Trigger |
|--------|---------|
| `daily_loss_limit_exceeded` | current_daily_loss >= daily_loss_limit |
| `daily_trade_cap_exceeded` | current_daily_trade_count >= daily_trade_cap |
| `event_limit_exceeded` | current_event_open_positions >= event_limit |
| `max_concurrent_positions_exceeded` | current_open_positions >= max_concurrent_positions |
| `below_min_position_size` | requested_position_size < min_position_size |
| `above_max_position_size` | requested_position_size > max_position_size |
