# v0.7.3 — Live Order Submission Seam Pack

## Summary

Introduces live order submission seam: status enum, request/result contracts, submission evaluator.
No live execution. No network calls. Clean seam for future live order client connection.

## OrderSubmissionStatus Values

| Value | Meaning |
|-------|---------|
| `submission_allowed_not_attempted` | Allowed but not yet attempted |
| `submission_blocked_preflight` | Preflight gate failed |
| `submission_blocked_outbound_guard` | v0.7.2 outbound guard failed |
| `submission_ready` | All guards passed — ready to submit |
| `submission_submitted` | Successfully submitted to exchange |
| `submission_rejected` | Exchange rejected the order |
| `submission_retryable_failure` | Transient failure, retry possible |
| `submission_terminal_failure` | Permanent failure, no retry |

## Evaluator Logic

| Check | Condition | Status |
|-------|-----------|--------|
| 1 | outbound_allowed=False | SUBMISSION_BLOCKED_OUTBOUND_GUARD |
| 2 | preflight_passed=False | SUBMISSION_BLOCKED_PREFLIGHT |
| 3 | All pass | SUBMISSION_READY (submission_allowed=True) |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Seam only — no network calls | Clean contract for future live client connection |
| outbound_guard checked before preflight | Guard is the immediate execution gate |
| outcome model carries retryable/terminal flags | Enables future retry/circuit-breaker logic |
| Guard results as booleans on request | Decoupled from upstream evaluator implementations |
