# Release Notes — v1.0.7 Admin Control + Visibility UI Completion Pack

## Summary
Admin panel wired to real user/entitlement API. Entitlement editor, user list, online summary metrics.

## What Changed

### Frontend
- AdminPanel.tsx: rewritten to use real /api/v1/admin/* data
- components/admin/AdminSummaryCards.tsx: new — metric cards (online count, positions, etc.)
- components/admin/AdminUserTable.tsx: new — clickable user list table
- components/admin/EntitlementEditor.tsx: new — inline entitlement editor
- hooks/useAdminUsers.ts: new — API integration for admin user/entitlement management
- types/auth.ts: new — shared auth/entitlement TypeScript types

### Backend Tests
- tests/api/test_admin_visibility.py: 6 new tests for admin route enforcement

## Architecture Notes
- Admin panel reads session_token from sessionStorage (key: polypro_session_token) via useAuth convention
- All admin API calls include X-Session-Token header
- Non-admin users get 403 from backend
- Entitlement enforcement: license_status=inactive always forces trading_enabled=false
- Visibility data (visible_panels, visible_rules, editable_rules) editable per user
- useEntitlement.ts already used X-Session-Token — no change required
