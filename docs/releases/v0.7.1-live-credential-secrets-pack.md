# v0.7.1 — Live Credential Integration + Secrets Handling Pack

## Summary

Introduces live credential store, secrets masking foundation, credential completeness evaluator, and a bridge to v0.7.0 readiness flags.
No live execution. No live API calls. Secrets never logged in plaintext or exposed to frontend.

## Changes

| File | Change |
|------|--------|
| `backend/app/domain/live/live_credentials.py` | New — `LiveCredentials` (7 credential fields, all default empty) |
| `backend/app/domain/live/secrets_masker.py` | New — `mask_secret()` utility |
| `backend/app/domain/live/secrets_result.py` | New — `SecretsResult` (is_complete + missing_fields + masked_summary) |
| `backend/app/domain/live/credential_evaluator.py` | New — `evaluate_credential_completeness()` |
| `backend/app/domain/live/credential_readiness_bridge.py` | New — `credentials_to_readiness_flags()` |
| `backend/tests/domain/live/test_credentials.py` | New — 34 credential/secrets tests |

## LiveCredentials Fields

| Field | Description |
|-------|-------------|
| `wallet_address` | On-chain wallet address |
| `private_key` | Private key for signing |
| `funder_address` | Funder wallet address |
| `relayer_api` | Relayer API endpoint |
| `api_key` | Exchange API key |
| `api_secret` | Exchange API secret |
| `api_passphrase` | Exchange API passphrase |

## SecretsResult Fields

| Field | Description |
|-------|-------------|
| `is_complete` | True when all 7 fields are non-empty |
| `missing_fields` | List of field names that are empty |
| `masked_summary` | Dict of field → masked value (safe for display/logging) |

## Masking Rules

| Input | Output |
|-------|--------|
| `""` (empty) | `"NOT_SET"` |
| 1–4 chars | `"****"` |
| 5+ chars | first 4 chars + `"****"` |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| All credential checks run (no short-circuit) | Operator needs full list of missing fields |
| masked_summary always built | Safe visibility without plaintext exposure |
| Bridge returns dict → LiveReadinessContext | No coupling between LiveCredentials and readiness evaluator |
| Empty string = absent | Simple, no None handling needed |
