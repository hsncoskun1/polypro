# v0.3.11 — Timeframe Mapping Integration Shell

## Summary

Wires `map_end_date_to_timeframe()` into the Polymarket client discovery chain only. ISO 8601 `end_date` strings from Polymarket rows are converted to `Timeframe` enum values in `discovery_client.py` before calling `map_to_raw_payload_item()`. The trigger API endpoint is unchanged. Past dates and unparseable strings raise `TimeframeMappingError` openly — no silent fallback.

## Changes

| File | Change |
|------|--------|
| `backend/app/services/discovery_client.py` | Calls `map_end_date_to_timeframe(pm.end_date)` before `map_to_raw_payload_item()`; uses `timeframe.value` in mapped `PolymarketMarketPayload` |
| `backend/tests/services/test_discovery_client.py` | Updated test data to ISO dates; added `TimeframeMappingError` propagation tests (past date, unparseable) |

## Files Unchanged

| File | Status |
|------|--------|
| `backend/app/adapters/external_payload.py` | Unchanged — `map_to_raw_payload_item()` accepts any non-empty string as `end_date` |
| `backend/app/api/discovery.py` | Unchanged — trigger endpoint uses Timeframe strings directly, no ISO date path |

## Integration Chain (post-v0.3.11)

```
PolymarketClient.fetch()
    → map_client_rows_to_payloads()         [dict → PolymarketMarketPayload]
    → map_end_date_to_timeframe(pm.end_date) ← v0.3.11 integration point
    → PolymarketMarketPayload(end_date=timeframe.value)
    → map_to_raw_payload_item()
    → RawPayloadItem.timeframe = "1D" / "1W" / "1M" / "3M"
    → PayloadDiscoveryAdapter
    → run_discovery_service()
```

## Error Behaviour

| Input | Result |
|-------|--------|
| Valid future ISO date | `Timeframe` enum value used |
| Past ISO date | `TimeframeMappingError` propagates from `run_polymarket_client_discovery()` |
| Unparseable string | `TimeframeMappingError` propagates |
| Empty `end_date` | Caught by `map_to_raw_payload_item()` → `ExternalPayloadMappingError` (defensive) |

## Design Decisions

- Integration in `discovery_client.py` only — trigger API endpoint (discovery.py) untouched
- `external_payload.py` contract unchanged — accepts any non-empty string
- `TimeframeMappingError` propagates from `run_polymarket_client_discovery()` (not caught)
- `ExternalPayloadMappingError` still caught defensively for whitespace-only fields
- No silent fallback anywhere in the Polymarket client chain
