# v0.3.8 — Polymarket Client to External Payload Mapping Shell

## Summary

Adds `map_client_rows_to_payloads()` — a mapping function that converts `list[dict]` (raw `PolymarketClient` output) to `list[PolymarketMarketPayload]`. Reads required fields, passes values as-is (whitespace normalization remains the external payload contract's responsibility), raises `ClientPayloadMappingError` on missing fields. Not wired to the discovery pipeline.

## Mapping Contract

**`map_client_rows_to_payloads(rows: list[dict]) -> list[PolymarketMarketPayload]`**

| Behaviour | Detail |
|-----------|--------|
| Valid row | Returns `PolymarketMarketPayload(condition_id, question, end_date)` |
| Whitespace values | Passed through as-is — normalization is contract layer's job |
| Missing required field | Raises `ClientPayloadMappingError("Row N missing required field 'X'")` |
| Empty list | Returns `[]` |
| No silent fallback | First missing field stops processing immediately |

Required dict keys: `condition_id`, `question`, `end_date`

## Design Decisions

- Whitespace is intentionally not stripped here — `map_to_raw_payload_item()` in `external_payload.py` owns that responsibility
- `ClientPayloadMappingError` is distinct from `ExternalPayloadMappingError` — different layers, different failure points
- Not wired to trigger/service/adapter chain — shell only
