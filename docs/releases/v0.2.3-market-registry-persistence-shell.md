# v0.2.3 — Market Registry Persistence Shell

## Summary

Markets are now persisted to a SQLite database. The in-memory registry is loaded from disk on startup and written on every mutation (create, status update). No data is lost on restart.

## Changes

| File | Change |
|------|--------|
| `backend/app/persistence/__init__.py` | New package |
| `backend/app/persistence/markets.py` | `SqliteMarketStore` with `load()` / `save()` using stdlib `sqlite3` |
| `backend/app/main.py` | Store instantiated in lifespan; registry hydrated from DB on startup |
| `backend/app/api/markets.py` | `store.save()` called after `POST /markets` and `PATCH /{id}/status` |
| `backend/tests/persistence/__init__.py` | New package |
| `backend/tests/persistence/test_market_store.py` | 7 unit tests for `SqliteMarketStore` |
| `backend/tests/api/test_markets_api.py` | `client` fixture uses `tmp_path` + `MARKET_STORE_PATH`; 1 persistence integration test |

## Configuration

| Env var | Default | Description |
|---------|---------|-------------|
| `MARKET_STORE_PATH` | `data/markets.db` | Path to SQLite database file |
