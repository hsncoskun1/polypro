# v1.0.1 — Request Signing + Auth Pack

## Scope

In this version: real HMAC-SHA256 Level 2 request signing, PolymarketRequestSigner, LiveCredentials hardening, fail-closed auth.
Not in this version: live order placement, balance fetch, fill stream, frontend changes.

## New Files

### `backend/app/domain/live/polymarket_request_signer.py`
HMAC-SHA256 Level 2 authentication signer. Builds all required Polymarket auth headers:
- `POLY_ADDRESS` — wallet address
- `POLY_SIGNATURE` — HMAC-SHA256 of timestamp + method + path + body
- `POLY_TIMESTAMP` — Unix timestamp (seconds)
- `POLY_NONCE` — nonce value
- `POLY_API_KEY` — api key
- `POLY_PASSPHRASE` — passphrase

Fail-closed: raises `PolymarketAuthError` if credentials missing.

## Modified Files

### `backend/app/domain/live/live_credentials.py`
Hardened credential container. All fields validated on construction.

## Fail-Closed Guarantees

- Missing credentials → PolymarketAuthError, no partial signing
- No silent fallback to unsigned requests
- No credential defaults that could produce invalid auth

## Test Coverage

- Full signing correctness tests
- Missing credential tests (all combinations)
- HMAC computation verification
