# v0.2.7 — Market Discovery Normalization Shell

## Summary

Adds a normalization layer between raw external source input and the discovery pipeline. `RawMarketItem` represents unvalidated external data. `normalize_item()` strips whitespace and raises `NormalizationError` on empty fields. `run_discovery_from_raw()` normalizes items, counts failures in `skipped_invalid_count`, and delegates to the existing `run_discovery()`. No HTTP, no scheduler, no auth — stub/static flow only.

## Normalization Contract

**Input:** `list[RawMarketItem]` — each item has `market_id`, `title`, `timeframe` (raw strings, may have whitespace or be empty)

**Normalization rules:**
- Whitespace stripped from all fields
- Empty `market_id`, `title`, or `timeframe` after stripping → `NormalizationError`

**Output:** `DiscoverySummary`
| Field | Description |
|-------|-------------|
| `added_count` | Markets successfully normalized and added to registry |
| `skipped_duplicate_count` | Items already in registry |
| `skipped_invalid_count` | Normalization failures + invalid timeframe errors |
| `total_seen` | Total raw items processed (including normalization failures) |
