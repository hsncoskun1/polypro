# Release Notes — v0.8.9 Admin Reporting + Operational Control UI Pack

**Version:** v0.8.9
**Branch:** feat/v0.8.9-admin-reporting-operational-control-ui-pack
**Status:** In progress

## Summary

Admin operational control and reporting UI surface. Real admin dashboard connecting to
`GET /admin/control-plane` endpoint. Operational control state, financial summary,
blocked events, execution/fill/claim events, operational alerts, release gate — all in
Türkçe. Admin surface shows broader data than user panel. User panel untouched.
