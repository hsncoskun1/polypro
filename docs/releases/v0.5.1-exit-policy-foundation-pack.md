# v0.5.1 — Exit Policy Foundation Pack

## Summary

Introduces the exit policy evaluator as a separate decision layer from execution.
Stop loss, take profit, and timeout conditions are evaluated from position context.
Execution applies the decision; it does not produce it. No force sell, no persistence,
no frontend changes in scope.

## Exit Policy Model

| Field | Meaning |
|-------|---------|
| `entry_price` | Price at position entry |
| `current_price` | Current market price |
| `side` | Trade direction — "YES" or "NO" |
| `stop_loss_threshold` | Absolute price move triggering stop loss |
| `take_profit_threshold` | Absolute price move triggering take profit |
| `time_remaining` | Remaining time; ≤ 0 triggers timeout |
| `should_exit` | True if any condition triggered |
| `exit_reason` | "stop_loss" / "take_profit" / "timeout" / "" |

## Exit Reason Codes

| Reason | Trigger |
|--------|---------|
| `stop_loss` | Loss move ≥ stop_loss_threshold |
| `take_profit` | Profit move ≥ take_profit_threshold |
| `timeout` | time_remaining ≤ 0 |
| `` (empty) | No condition triggered |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Evaluation order: stop_loss → take_profit → timeout | Capital preservation first |
| Direction-aware profit/loss calculation | YES and NO positions have opposite gain/loss directions |
| Exit policy separate from execution | Execution layer only applies the decision |
| Never returns None | All paths return a fully populated ExitDecision |
| Force sell | NOT in scope — v0.5.2+ |
| Persistence | NOT in scope — v0.5.2+ |
| Runtime state not mutated | Pure function — evaluator reads context, produces decision |

## Correct Flow

```
open_position → exit_policy_evaluator → exit_decision → execution_exit
```
