# v0.5.3 — Position Lifecycle Persistence Pack

## Summary

Introduces position lifecycle persistence foundation. Full snapshot of each position
including trigger/submitted/fill price ayrımı, entry/exit reason, requested/filled size,
and restart recovery seams. No PnL accounting, no sizing, no claim, no risk engine.

## Position Snapshot Fields

| Field | Description |
|-------|-------------|
| `position_id` | Unique position record identifier |
| `event_key` | Market event key |
| `side` | YES or NO |
| `status` | PositionState (OPEN / CLOSED) |
| `trigger_price` | Price at rule trigger moment |
| `order_submitted_price` | Price at order submission moment |
| `fill_price` | Actual fill price |
| `trigger_move_value` | Price move at trigger |
| `fill_move_value` | Price move at fill |
| `requested_size` | Size requested at entry |
| `filled_size` | Actual filled size |
| `entry_reason` | Rule/condition that triggered entry |
| `exit_reason` | Rule/condition that triggered exit (empty if open) |
| `opened_at` | ISO 8601 UTC timestamp |
| `closed_at` | ISO 8601 UTC timestamp (None if open) |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| trigger / submitted / fill are distinct fields | These are different execution moments and must not be collapsed |
| SQLite persistence | Consistent with existing market store pattern |
| open_position() inserts, close_position() updates | Records are never deleted — closed positions remain for audit |
| load_open_positions() excludes closed | Active position set stays clean; closed positions don't pollute recovery |
| restore_locks_from_positions() pure function | Derives lock set from position list; no side effects |
| PnL accounting NOT in scope | fill_price is stored as a field only; authoritative PnL is a future scope |
| Persistence/claim/sizing NOT in scope | Out of scope for this version |
