# v0.6.1 — Simulation Control Plane Pack

## Summary

Introduces simulation control plane read model foundation.
PositionView read model for individual positions (open and closed).
ControlPlaneSnapshot assembling all visibility surfaces into one read model.
Trigger / fill / current price and move value separation preserved.
Session PnL and balance visibility. Claim/settlement visibility.
Turkish UI label mapping foundation.
No new trading logic, no risk/sizing/claim changes, no admin UI.

## ControlPlaneSnapshot Fields

| Field | Description |
|-------|-------------|
| `open_positions` | List of PositionView for open positions |
| `closed_positions` | List of PositionView for closed positions |
| `session_realized_pnl` | Session realized PnL |
| `session_unrealized_pnl` | Session unrealized PnL |
| `session_total_pnl` | Session total PnL |
| `total_balance` | Total account balance |
| `available_balance` | Available balance |
| `current_balance` | Current balance (realized effects only) |
| `session_start_balance` | Balance at session start |
| `claim_status` | Current claim lifecycle status |
| `claim_available` | Whether claim is available |
| `claimed_amount` | Amount claimed |
| `settlement_completed_at` | Settlement completion timestamp |

## PositionView Fields

| Field | Description |
|-------|-------------|
| `trigger_price` / `entry_fill_price` / `current_price` / `exit_fill_price` | Four distinct price moments |
| `trigger_move_value` / `fill_move_value` / `current_move_value` | Three distinct move value moments |
| `realized_pnl` / `unrealized_pnl` | PnL — always separate |
| `status` | "open" or "closed" |
| `entry_reason` / `exit_reason` | Decision metadata |
| `opened_at` / `closed_at` | Lifecycle timestamps |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| open_positions and closed_positions always separate | Never mixed in a single list |
| Trigger / fill / current never collapsed | Binding project decision |
| Assembler makes copy of position lists | Prevents external mutation of snapshot state |
| TURKISH_LABELS is a plain dict | Simple, no framework dependency, UI-layer agnostic |
| Assembler does not compute — only assembles | All values come from upstream domain evaluators |
