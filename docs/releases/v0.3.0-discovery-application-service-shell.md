# v0.3.0 — Discovery Application Service Shell

## Summary

Wraps the discovery pipeline in a clean application service layer. `run_discovery_service()` accepts a `RawDiscoverySource`, runs the pipeline, and returns a `DiscoveryResult` containing the summary plus `source_name` and `ran_at` metadata. No HTTP endpoint, no scheduler, no real source — pipeline wiring only.

## Service Contract

**Input:**
- `source: RawDiscoverySource` — raw item provider
- `registry: InMemoryMarketRegistry` — target registry
- `source_name: str` (keyword, default `"unknown"`) — metadata label

**Output: `DiscoveryResult`**
| Field | Description |
|-------|-------------|
| `summary` | `DiscoverySummary` from pipeline — added / skipped counts / total_seen |
| `source_name` | Caller-supplied label for the source |
| `ran_at` | UTC datetime of execution |
