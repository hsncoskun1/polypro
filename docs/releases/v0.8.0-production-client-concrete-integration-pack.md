# v0.8.0 — Production Client Concrete Integration Pack

## Summary

Introduces concrete production exchange client integration: external payload models,
production request/response mappers, adapter error translator, and concrete
ProductionExchangeClient class implementing LiveExchangeClient ABC.
Business logic receives typed adapter responses — never raw exchange payloads.
No real network calls. Network seam points (_execute_*) ready for future HTTP/WS wiring.

## Architecture

```
AdapterSubmitRequest
  ↓ ProductionRequestMapper.map_submit_request()
ExternalSubmitPayload
  ↓ ProductionExchangeClient._execute_submit()  [seam → future HTTP/WS]
ExternalResponsePayload
  ↓ ProductionResponseMapper.map_submit_response()
     + AdapterErrorTranslator.translate_status()
AdapterSubmitResponse → business logic
```

## Error Translator Priority

| Priority | Condition | AdapterOutcomeStatus |
|----------|-----------|----------------------|
| 1 | terminal_failure=True | ADAPTER_TERMINAL_FAILURE |
| 2 | retryable=True | ADAPTER_RETRYABLE_FAILURE |
| 3 | mapped_status lookup | enum value |
| 4 | Unknown status | ADAPTER_SUBMITTED (fail-closed) |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Fail-closed unknown status | Unknown exchange response → ADAPTER_SUBMITTED, not silently ok |
| Separate request/response mappers | Single responsibility — easy to swap per exchange |
| _execute_* seam methods | Network integration point isolated — not polluting business logic |
| No network calls | Seam only — ready for real Polymarket HTTP/WS client |
