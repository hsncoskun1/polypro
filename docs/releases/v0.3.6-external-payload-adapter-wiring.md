# v0.3.6 — External Payload Adapter Wiring

## Summary

Wires the external payload contract (v0.3.5) into the trigger endpoint's adapter path. Request body items are now routed through `PolymarketMarketPayload` → `map_to_raw_payload_item()` → `PayloadDiscoveryAdapter` before reaching the service layer. Request shape is unchanged. Full chain: API → external payload mapper → adapter → service → pipeline.

## Changes

| File | Change |
|------|--------|
| `backend/app/api/discovery.py` | Updated — items mapped through `PolymarketMarketPayload` + `map_to_raw_payload_item()` before adapter |

## Full Chain (after v0.3.6)

```
POST /api/v1/discovery/trigger
         │ RawMarketItemSchema
         ▼
  PolymarketMarketPayload    ← v0.3.5 (external format)
         │ map_to_raw_payload_item()
         ▼
    RawPayloadItem           ← v0.3.3 (adapter input)
         │ PayloadDiscoveryAdapter.fetch()
         ▼
   run_discovery_service()   ← v0.3.0
         │
         ▼
     run_pipeline()          ← v0.2.8
```
