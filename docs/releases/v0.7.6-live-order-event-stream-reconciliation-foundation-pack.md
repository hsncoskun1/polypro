# v0.7.6 — Live Order Event Stream + State Reconciliation Foundation Pack

## Summary

Introduces live order event stream and state reconciliation foundation: event type enum,
event record model, order state model, reconciliation result model, and reconciler function.
Submission / response / fill / cancel / replace results unified into single lifecycle.
No websocket/client. No network calls. Seam only.

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Events applied in caller-supplied order | Caller responsible for ordering; seam stays clean |
| Idempotent application seam | Each event updates state — deduplication engine is future scope |
| Terminal events: filled, cancelled, rejected, expired, failed | Clean lifecycle finality |
| cancel_requested and replace_requested are non-terminal | Intermediate intents, not final outcomes |
| v0.7.3/v0.7.5 seams preserved | Reconciler unifies — does not replace submission/cancel/replace seams |
| No websocket/client | Foundation seam for future event consumer |
