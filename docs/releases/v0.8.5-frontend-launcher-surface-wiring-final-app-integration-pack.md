# Release Notes — v0.8.5 Frontend/Launcher Surface Wiring + Final App Integration Pack

**Version:** v0.8.5
**Branch:** feat/v0.8.5-frontend-launcher-surface-wiring-final-app-integration-pack
**Status:** In progress

## Summary

Surface integration layer connecting backend readiness/release gate results to
user and admin views. Turkish label mapping throughout. launcher_blocked gates
user panel access. Admin has broader visibility than user. Secrets never included.
live_applied_testing_ready always separate from release_ready.

## Key Behaviors

- launcher_blocked=True → visible_panels=[] for user; blocked_reason_messages set
- Admin visible_panels is superset of user visible_panels
- Turkish labels applied via surface_label_mapper
- release_ready and live_applied_testing_ready always shown separately
- live mode not ready → live_mode_ui_blocked=True
- Secrets never in any surface view
- Admin has safe_stop, scheduler, operational_alerts, blocked_trades etc.
