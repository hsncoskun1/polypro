# v1.1.1 — User Rule/Edit Visibility Enforcement Completion Pack

## Summary

Enforces `visible_rules` and `editable_rules` entitlement fields on the user-facing panel. Adds `RulesPanel` component showing strategy rules gated by entitlement.

## Changes

### Frontend
- `src/components/RulesPanel.tsx` — NEW: shows strategy rules filtered by `visible_rules`; marks each rule as Düzenlenebilir or Salt Okunur per `editable_rules`
- `src/routes/UserPanel.tsx` — extracts `visible_rules` + `editable_rules` from entitlement; adds `RulesPanel` behind `isPanelVisible('rules', visiblePanels)` gate
- `src/test/rule-visibility.test.tsx` — NEW: 17 tests for RulesPanel visibility, editability, UserPanel gate

## Enforcement Rules
- `visible_rules` empty → all 6 known rules shown (time, price, move, spread, event_limit, max_positions)
- `visible_rules` non-empty → only listed rules shown
- `editable_rules` → matching rules show "Düzenlenebilir", others show "Salt Okunur"
- `visible_panels` excludes "rules" → RulesPanel not rendered
