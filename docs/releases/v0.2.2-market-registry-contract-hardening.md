# Release Note — v0.2.2 Market Registry Contract Hardening

## Purpose
Harden the market registry domain and API contract before connecting discovery. Deterministic ordering, tighter validation, expanded test coverage.

## What Was Done
- `backend/app/domain/markets/registry.py` — `list()` now returns markets sorted by `market_id` for deterministic ordering
- `backend/tests/domain/test_market_registry.py` — 4 new domain tests (order determinism, status round-trip, idempotent status update)
- `backend/tests/api/test_markets_api.py` — 5 new API tests (list order, active order, invalid status 422, missing field 422, empty body 422)

## Test Summary
- Framework: pytest + FastAPI TestClient
- API tests: 15 / 15 PASSED
- Domain tests: 14 / 14 PASSED
- Health tests: 3 / 3 PASSED
- Total: 32 / 32 PASSED

## Contract Changes
- `GET /api/v1/markets` — always sorted by `market_id` (deterministic)
- `GET /api/v1/markets/active` — always sorted by `market_id` (deterministic)
- `PATCH /markets/{id}/status` — invalid status value returns 422
- `POST /api/v1/markets` — missing required fields return 422
