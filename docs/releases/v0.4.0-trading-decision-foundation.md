# v0.4.0 — Trading Decision Foundation Pack

## Summary

Introduces the trading entry decision engine. Discovers which markets are eligible for entry based on a full set of configurable rules. No execution, no simulation — decision only. This is the first version where the system can say "yes/no" to a trade.

## Entry Rules

| Rule | Trigger |
|------|---------|
| `time_rule` | `trading_start <= current_time <= trading_end` |
| `price_rule` | `price_min <= current_price <= price_max` |
| `move_rule` | `abs(current_price - ptb) >= move_threshold` |
| `spread_rule` | `spread <= spread_max` |
| `event_limit_rule` | `daily_event_count < event_limit` |
| `max_positions_rule` | `open_position_count < max_positions` |

## Move Rule Design Decisions

- `move = current_price - ptb` — single authoritative formula
- Two-directional: both up and down moves qualify
- Absolute numeric only — no percent mode
- Trigger: `abs(move) >= threshold` (inclusive boundary)

## Rule State Model

| State | Meaning |
|-------|---------|
| `pass` | Rule condition met |
| `fail` | Rule condition not met — blocks trade |
| `waiting` | Condition not yet evaluable (reserved for future use) |
| `disabled` | Rule turned off — excluded from pass/fail count |
| `locked_by_admin` | Rule locked by admin policy (reserved for v0.4.1) |
