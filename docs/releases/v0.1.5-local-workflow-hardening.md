# Release Note — v0.1.5 Local Workflow Hardening

## Purpose
Harden the launcher with pre-flight checks, early-exit detection, and clear error messages to improve local developer experience.

## What Was Done
- `launcher/src/launcher.py` — added:
  - `check_preflight()` — validates BACKEND_DIR, venv python, FRONTEND_DIR, node_modules before starting
  - `_check_early_exit()` — detects if backend crashes immediately after launch (0.5s window)
  - `run()` hardened: preflight → start_backend → early exit check → start_frontend → health wait → open browser
  - `start_backend` / `start_frontend` now capture stdout+stderr via `subprocess.PIPE`
- `launcher/tests/test_launcher.py` — expanded from 5 to 14 tests covering all new paths
