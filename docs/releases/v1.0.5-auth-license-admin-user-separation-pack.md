# v1.0.5 — Auth + License + Admin/User Separation Foundation Pack

## Summary

This release establishes the authentication, licensing, and admin/user separation foundation for POLYPRO. It introduces session-based login, per-user entitlements, and role-based route guards.

- `app/domain/auth/user_role.py` — `UserRole` enum (`user`, `admin`)

## Auth Design Decisions

- Session token uses `X-Session-Token` header (not Bearer/Authorization)
- Password hash uses SHA-256 (production upgrade path: bcrypt)
- Forgot-password returns reset token directly (production: email delivery)
- Admin boundary enforced in `_require_admin()` — role checked against session
- `trading_enabled` is always recomputed by `apply_license_enforcement` — cannot be set to `True` with inactive license

## Risks

- SHA-256 password hashing is not production-grade; bcrypt upgrade required before live user-facing deployment
- Forgot-password endpoint returns reset token in response body (acceptable for foundation; production requires email delivery)
- No session expiry TTL implemented in this version
