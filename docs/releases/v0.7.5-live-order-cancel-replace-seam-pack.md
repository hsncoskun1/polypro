# v0.7.5 — Live Order Cancel/Replace Seam Pack

## Summary

Introduces live order cancel and replace seam: status enums, request/result contracts, evaluators.
Cancel and replace are separate lifecycle intents — never collapsed.
No live execution. No network calls.

| 4 | All clear | READY |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Cancel and replace are separate intents | Never collapsed — different lifecycle semantics |
| order_id required before preflight | Cannot cancel/replace a non-existent reference |
| Seam only — no network calls | Clean contract for future exchange client |
| Same guard priority pattern as v0.7.3 | Consistent across all live outbound actions |
