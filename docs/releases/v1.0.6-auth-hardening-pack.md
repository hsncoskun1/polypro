# Release Notes — v1.0.6 Auth Hardening Pack

## Summary
Auth security hardening: bcrypt password hashing, session TTL/expiry, reset token expiry and single-use invalidation.

## What Changed

### Backend
- `auth_service.py`: SHA-256 replaced with bcrypt; session_created_at, session_expires_at added; reset token expiry + single-use enforcement
- `user.py`: Added session_created_at, session_expires_at, password_reset_requested_at, password_reset_expires_at
- `auth_store.py`: New columns persisted; migration for existing DBs via ALTER TABLE
- `deps.py`: get_current_user now validates session expiry via is_session_valid()
- `requirements.txt`: bcrypt==4.1.3 added

### Tests
- test_auth_service.py: Full bcrypt, session TTL, reset token expiry coverage
- test_auth_store.py: New timestamp column persistence tests

## Security Notes
- bcrypt with random salt; two hashes of same password always differ
- Sessions expire after 24 hours by default (SESSION_TTL_HOURS)
- Reset tokens expire after 60 minutes (RESET_TOKEN_TTL_MINUTES)
- Reset tokens are single-use; invalidated after successful use
- Expired sessions rejected at API layer (deps.py)
