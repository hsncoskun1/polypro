# v0.3.20 — Discovery Scheduler Hardening

## Summary

Hardens the `DiscoveryScheduler` and its config with input validation, lifecycle safety guards, and 8 new targeted tests. No new features — this version closes operational edge cases introduced in v0.3.19.

## Changes

| File | Change |
|------|--------|
| `backend/app/core/scheduler.py` | `ValueError` on invalid interval; double-start protection; `_thread = None` after stop |
| `backend/app/core/config.py` | `ValueError` if `DISCOVERY_SCHEDULER_INTERVAL < 1` at startup |
| `backend/tests/core/test_scheduler.py` | 8 new hardening tests added |

## Hardening Details

| Guard | Behaviour |
|-------|-----------|
| `interval_seconds < 1` | Raises `ValueError` at construction time |
| `DISCOVERY_SCHEDULER_INTERVAL < 1` (env) | Raises `ValueError` at app startup |
| `start()` called while thread alive | Logs warning, returns — no second thread created |
| `stop()` called when not started | No-op — does not raise |
| `stop()` called twice | Safe — second call is a no-op |
| `_thread` after `stop()` | Set to `None` |
| Tick error followed by next tick | Guard released after error; next tick runs normally |

  - `tests/core/test_scheduler.py` — 16 tests total (8 original + 8 new hardening)
  - All other suites — zero regressions
