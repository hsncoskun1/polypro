# v0.7.2 — Live Execution Preflight + Outbound Guard Pack

## Summary

Introduces fail-closed outbound guard: live execution only proceeds when all preflight conditions pass.
Simulation mode explicitly blocked. No live execution, no live API calls.

## PreflightContext Fields

| Field | Description |
|-------|-------------|
| `simulation_mode_default` | System is in simulation default state |
| `live_mode_requested` | Live mode has been requested |
| `live_mode_enabled` | Live mode is currently enabled |
| `explicit_live_enable` | Operator has consciously activated live mode |
| `credentials_complete` | All 7 live credentials are present |
| `verification_passed` | Verification gate passed |
| `sizing_passed` | Sizing gate passed |
| `risk_passed` | Risk gate passed |
| `outbound_action_type` | The outbound action being guarded |

| Value | Meaning |
|-------|---------|
| `live_order_submit` | Submitting a live order |
| `live_order_cancel` | Cancelling a live order |
| `live_claim_submit` | Submitting a live claim |
| `other_live_outbound` | Any other live outbound action |

## Evaluator Design

| Gate | Condition | Result |
|------|-----------|--------|
| Gate 1 | simulation_mode_default=True AND NOT live_mode_requested | outbound_allowed=False, ["outbound_not_allowed_in_simulation"] — stops |
| Gate 2+ | all remaining checks — no short-circuit | outbound_allowed=(no blockers), all active blockers collected |

## Blocker Reason Codes

| Reason | Trigger |
|--------|---------|
| `outbound_not_allowed_in_simulation` | simulation_mode_default=True AND NOT live_mode_requested (Gate 1) |
| `explicit_live_enable_required` | explicit_live_enable=False |
| `live_mode_not_enabled` | live_mode_enabled=False |
| `live_credentials_incomplete` | credentials_complete=False |
| `verification_not_passed` | verification_passed=False |
| `sizing_not_passed` | sizing_passed=False |
| `risk_not_passed` | risk_passed=False |

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Fail-closed | outbound_allowed=False unless all conditions pass |
| Simulation gate returns single clean blocker | Not a failure state — normal operation mode |
| All live-path checks run (no short-circuit) | Operator needs full list of active blockers |
| outbound_action_type carried on context | Guard is action-aware for future extension |
| Upstream gate results as booleans | Decoupled from upstream evaluator implementations |
