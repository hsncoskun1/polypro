# Iteration — v0.5.3 Position Lifecycle Persistence Pack

## Scope

Position lifecycle persistence foundation. Full snapshot model with trigger/submitted/fill
price ayrımı. Open/close persistence, restart recovery seam, lock restore seam.
No PnL accounting, no claim, no sizing, no risk engine.

## What Changed

- `position_state.py`: `PositionState` — OPEN / CLOSED enum
- `persisted_position.py`: `PersistedPosition` — full snapshot dataclass
- `position_store.py`: `SqlitePositionStore` — open/close/load/all + `restore_locks_from_positions()`
- `tests/domain/position/`: 9 model tests
- `tests/persistence/test_position_store.py`: 15 persistence tests

## Architecture

```
PersistedPosition (snapshot)
  position_id, event_key, side, status
  trigger_price | order_submitted_price | fill_price
  trigger_move_value | fill_move_value
  requested_size | filled_size
  entry_reason | exit_reason
  opened_at | closed_at
        │
        ▼
SqlitePositionStore
  open_position(position)       → INSERT
  close_position(id, reason, ts) → UPDATE status/exit_reason/closed_at
  load_open_positions()          → SELECT WHERE status=OPEN
  load_all_positions()           → SELECT all
        │
        ▼
restore_locks_from_positions(positions) → set[event_key]
  Used after restart to restore ExecutionLock state
```
