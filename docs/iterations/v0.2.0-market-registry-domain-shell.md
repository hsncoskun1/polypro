# Iteration Summary — v0.2.0 Market Registry Domain Shell

## Scope
Build the market registry domain layer: entity, value objects, lifecycle rules, in-memory registry, domain exceptions.

## Status
Branch pushed, not yet merged to main.

## What Changed
- `backend/app/domain/` — new domain package
- `backend/app/domain/markets/` — model, exceptions, registry
- `backend/tests/domain/` — 10 domain tests

## Architecture Decisions
- `Market` is a plain dataclass — no ORM, no persistence coupling
- `Timeframe` and `MarketStatus` are `str` enums for easy serialization later
- `InMemoryMarketRegistry` is a plain class — no DI framework dependency
- `parse_timeframe()` is a standalone helper to translate string → enum with domain exception

- 10 / 10 PASSED

## Notes
- No API surface created — domain layer only
- Discovery, persistence, and API layers come in future versions
