# Iteration — v0.3.7 External Source Client Shell

## Scope

Establishes the minimum HTTP client surface for fetching external Polymarket market data. No wiring to the discovery pipeline, no auth, no retry.

## What Changed

New `backend/app/clients/` package containing `PolymarketClient`:
- Accepts a URL and optional timeout
- Calls `httpx.get()`, parses JSON, returns `list[dict]`
- Raises `PolymarketClientError` on any failure — no silent fallback

## Position in Architecture

```
[external: Polymarket API]
         │ HTTP GET
         ▼
  PolymarketClient.fetch()   ← v0.3.7 (shell only, not yet wired)
         │ list[dict]
         ▼
  [future: PolymarketMarketPayload mapping — v0.3.8+]
         │
         ▼
  PolymarketMarketPayload    ← v0.3.5
         │ map_to_raw_payload_item()
         ▼
    RawPayloadItem / PayloadDiscoveryAdapter / run_discovery_service()
```
