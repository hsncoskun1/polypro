# Iteration — v0.5.5 Order Sizing + Min/Max Order Constraints Pack

## Scope

Order sizing mode selection and admin-controlled constraint enforcement.
Fixed amount and available-balance-percent modes. Min/max order size.
Minimum available balance to trade. Disallowed mode block.
No claim, no risk engine, no UI, no live exchange constraints.

## What Changed

- `sizing_mode.py`: `SizingMode` — FIXED_AMOUNT, AVAILABLE_BALANCE_PERCENT
- `sizing_policy.py`: `SizingPolicy` — admin-controlled constraints
- `sizing_context.py`: `SizingContext` — input contract
- `sizing_result.py`: `SizingResult` — output with size_allowed, normalized_order_amount, sizing_reason
- `sizing_evaluator.py`: `evaluate_order_size()` — 8-step evaluation with ordered constraint checks
- Tests: 28 new in test_sizing_evaluator.py

## Architecture

```
SizingContext (input)
  sizing_mode, available_balance, total_balance, policy,
  fixed_amount, available_balance_percent
        │
        ▼
evaluate_order_size()
  1. disallowed_sizing_mode check
  2. below_min_available_balance_to_trade check
  3. raw amount computation (fixed or percent)
  4. normalized_amount_zero_or_invalid check
  5. insufficient_available_balance check
  6. below_min_order_size check
  7. above_max_order_size check
  8. normalize + return allowed
        │
        ▼
SizingResult (output)
  size_allowed, normalized_order_amount, sizing_reason
```
