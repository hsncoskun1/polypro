# Iteration — v0.3.17 Discovery Run Status Shell

## Scope

Adds run lifecycle state tracking and `GET /api/v1/discovery/status` endpoint. No scheduler, no auth changes, no persistence.

## What Changed

- `backend/app/core/run_status.py`: new `DiscoveryRunStatus` dataclass
- `backend/app/main.py`: `app.state.discovery_run_status` initialised at startup
- `backend/app/api/discovery.py`: status updated at run start, success, and error; new GET /status endpoint
- `backend/app/api/schemas/discovery.py`: new `DiscoveryRunStatusResponse` schema
- `backend/tests/api/test_discovery_api.py`: 7 new status tests

## Status Fields

| Field | Type | Description |
|-------|------|-------------|
| `is_running` | bool | True while run is in progress |
| `last_finished_at` | datetime? | When last run completed (success or error) |
| `last_success_at` | datetime? | When last successful run completed |
| `last_result_summary` | dict? | Summary counts from last successful run |
| `last_error` | str? | Error detail from last failed run; null on success |
