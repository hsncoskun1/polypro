# Iteration — v0.5.2 Force Sell Pack

## Scope

Force sell decision layer within exit policy. Entry/fill-based adverse move.
Three independent conditions with any/all combinator. Side-aware calculation.
No persistence, no PnL accounting.

## What Changed

- `force_sell_context.py`: `ForceSellContext` — all force sell fields
- `force_sell_decision.py`: `ForceSellDecision` — should_force_sell, reason
- `force_sell_evaluator.py`: `evaluate_force_sell(ctx)` — condition + combinator logic
- `tests/domain/force_sell/`: 27 new tests

## Architecture

```
ForceSellContext (input)
        │
        ▼
evaluate_force_sell()
        │
        ├─ 0 enabled conditions     → ForceSellDecision(False, "")
        ├─ 1 enabled, triggered     → ForceSellDecision(True, specific_reason)
        ├─ 1 enabled, not triggered → ForceSellDecision(False, "")
        ├─ N enabled, "any", 1+ fire  → ForceSellDecision(True, "force_sell_combined_any")
        ├─ N enabled, "all", all fire → ForceSellDecision(True, "force_sell_combined_all")
        └─ N enabled, "all", partial  → ForceSellDecision(False, "")
        │
        ▼
ForceSellDecision
  should_force_sell = True/False
  reason = specific | combined | ""
        │
        ▼
execution_exit (v0.5.0)  ← applies the decision
```
