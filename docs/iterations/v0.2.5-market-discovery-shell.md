# Iteration Notes — v0.2.5 Market Discovery Shell

## Goal

Build the clean, minimal foundation for the market discovery layer. Establish input/output contract before adding source mapping, filtering, and refresh behavior.

## Decisions

- **`run_discovery(items, registry)`**: single function, no class. Takes stub/static list, applies to registry, returns summary.
- **`DiscoveryItem`**: unvalidated input — raw `timeframe` string. Validation happens inside `run_discovery()` via `parse_timeframe()`.
- **`DiscoverySummary`**: dataclass with `added_count`, `skipped_duplicate_count`, `skipped_invalid_count`, `total_seen`. No silent fallback — all skipped items are counted.
- **Reuses existing domain**: `parse_timeframe()`, `DuplicateMarketError`, `InvalidTimeframeError` from existing registry/exceptions. No new domain abstractions needed.
- **No API endpoint**: discovery is domain-only this turn. Not wired into main.py lifespan yet.
- **No persistence changes**: discovery operates on registry only; persistence is registry responsibility.
