# Iteration — v0.3.19 Discovery Scheduler Shell

## Scope

Adds periodic discovery scheduler. Disabled by default. Integrates with existing run guard and run status. No new API endpoints, no auth changes.

## What Changed

- `backend/app/core/scheduler.py`: new `DiscoveryScheduler` class
- `backend/app/core/config.py`: `DISCOVERY_SCHEDULER_ENABLED`, `DISCOVERY_SCHEDULER_INTERVAL` config
- `backend/app/main.py`: scheduler created and started at startup, stopped at shutdown
- `backend/tests/core/test_scheduler.py`: 8 new scheduler unit tests

## Scheduler Fields

| Env Var | Default | Description |
|---------|---------|-------------|
| `DISCOVERY_SCHEDULER_ENABLED` | `false` | Enable periodic discovery |
| `DISCOVERY_SCHEDULER_INTERVAL` | `3600` | Tick interval in seconds |
