# Iteration — v0.7.1 Live Credential Integration + Secrets Handling Pack

## Scope

Live credential store, secrets masking, completeness evaluator, readiness bridge.
No live execution. No live API calls. Secrets foundation only.

## What Changed

- `live_credentials.py`: `LiveCredentials` — 7 credential fields, all default empty
- `secrets_masker.py`: `mask_secret()` — NOT_SET / **** / first4****
- `secrets_result.py`: `SecretsResult` — is_complete, missing_fields, masked_summary
- `credential_evaluator.py`: `evaluate_credential_completeness()` — all checks run, no short-circuit
- `credential_readiness_bridge.py`: `credentials_to_readiness_flags()` — LiveCredentials → presence flags for LiveReadinessContext
- Tests: 34 new in test_credentials.py

## Architecture

```
LiveCredentials (store)
  wallet_address, private_key, funder_address, relayer_api
  api_key, api_secret, api_passphrase
        │
        ├──► evaluate_credential_completeness()
        │         [all 7 checks — no short-circuit]
        │         masked_summary built (no plaintext)
        │         ▼
        │    SecretsResult
        │      is_complete = len(missing) == 0
        │      missing_fields = [all absent]
        │      masked_summary = {field: masked_value}
        │
        └──► credentials_to_readiness_flags()
                  wallet_address_present: bool(wallet_address)
                  private_key_present:    bool(private_key)
                  funder_address_present: bool(funder_address)
                  relayer_api_present:    bool(relayer_api)
                  api_key_present:        bool(api_key)
                  api_secret_present:     bool(api_secret)
                  api_passphrase_present: bool(api_passphrase)
                  ▼
             feeds → LiveReadinessContext (v0.7.0)
                  ▼
             evaluate_live_readiness() → LiveReadinessResult
```
