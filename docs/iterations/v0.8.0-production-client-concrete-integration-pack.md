# Iteration — v0.8.0 Production Client Concrete Integration Pack

## Scope

Concrete production exchange client. External payload models, request/response mappers,
error translator, ProductionExchangeClient concrete class.
No network calls — seam points (_execute_*) ready for future HTTP/WS wiring.

## What Changed

- `external_submit_payload.py`: `ExternalSubmitPayload` — outbound submit payload to exchange
- `external_cancel_payload.py`: `ExternalCancelPayload` — outbound cancel payload to exchange
- `external_replace_payload.py`: `ExternalReplacePayload` — outbound replace payload to exchange
- `external_response_payload.py`: `ExternalResponsePayload` — inbound response from exchange (shared)
- `adapter_error_translator.py`: `translate_status()` — maps raw status + failure flags → AdapterOutcomeStatus
- `production_request_mapper.py`: `ProductionRequestMapper` — adapter request → external payload
- `production_response_mapper.py`: `ProductionResponseMapper` — external payload → adapter response
- `production_exchange_client.py`: `ProductionExchangeClient` — concrete LiveExchangeClient implementation
- Tests: 36 new in test_production_client_concrete.py

## Architecture

```
[Internal: adapter contracts]
AdapterSubmitRequest / AdapterCancelRequest / AdapterReplaceRequest
  │
  ↓ ProductionRequestMapper
ExternalSubmitPayload / ExternalCancelPayload / ExternalReplacePayload
  │
  ↓ ProductionExchangeClient._execute_*()  ← seam point for future REST/WS
ExternalResponsePayload
  │
  ↓ ProductionResponseMapper + AdapterErrorTranslator
AdapterSubmitResponse / AdapterCancelResponse / AdapterReplaceResponse / AdapterOrderUpdate
  │
[Internal: business logic / orchestrator — never sees raw exchange payload]
```
