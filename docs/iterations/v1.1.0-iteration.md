# Iteration — v1.1.0 Launcher Authority + Bootstrap Gate Pack

## Scope
Single version. Launcher authority model: cryptographic grant token generated by launcher, passed to backend subprocess, backend gates operational routes.

## Decisions
- `secrets.token_hex(32)` used for grant token — random, not guessable
- Token passed via env var (not CLI arg) to avoid shell history exposure
- `GET /api/v1/launcher/status` always open — frontend can check before session auth
- Gate applies to: control_plane, admin_control_plane, admin_users, user_entitlement
- Gate does NOT apply to: health, readiness, launcher, auth, settings, markets, discovery
- Frontend shows amber warning banner when `grant_required=true` and `launched=false`
