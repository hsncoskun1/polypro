# Iteration — v0.5.4 Execution Fill + PnL Accounting Pack

## Scope

Execution fill lifecycle accounting and PnL/balance foundation.
Fill-price based. Full trigger/submitted/fill/current separation.
Session PnL and balance tracking. Event/log record model.
No claim, no sizing, no risk engine.

## What Changed

- `accounting_context.py`: `AccountingContext` — input contract
- `accounting_snapshot.py`: `AccountingSnapshot` — full output snapshot
- `pnl_evaluator.py`: `compute_unrealized_pnl()`, `compute_realized_pnl()`, `compute_move_value()`
- `entry_fill_accounting.py`: `compute_entry_fill_accounting()`
- `exit_fill_accounting.py`: `compute_exit_fill_accounting()`
- `event_type.py`: `EventType` — 11 lifecycle event types
- `event_record.py`: `EventRecord` — structured event record
- Tests: 46 new across accounting and event_log suites

## Architecture

```
AccountingContext (input)
  side, entry prices (trigger/submitted/fill), exit prices,
  current_price, sizes, balances, prior_session_pnl, claim_seam
        │
        ├─ compute_entry_fill_accounting() → AccountingSnapshot (open position)
        │    unrealized_pnl computed, realized=0, exit prices=0
        │
        └─ compute_exit_fill_accounting() → AccountingSnapshot (closed position)
             realized_pnl computed (fill-based), unrealized=0
        │
        ▼
AccountingSnapshot
  All 23 fields including trigger/submitted/fill separation,
  move values, PnL fields, session fields, balance fields

EventRecord
  event_type (EventType enum), event_key, timestamp, payload
  11 event types: entry/exit two-phase + position + claim seams + balance seam
```
