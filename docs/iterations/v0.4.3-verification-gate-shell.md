# Iteration — v0.4.3 Verification Gate Shell

## Scope

Verification gate hard-block layer. Strategy entry decision and verification gate are independent — both must pass before a trade is considered. Fail-closed. No execution, no force sell, no UI.

## What Changed

- `verification_context.py`: `VerificationContext` — ref_valid, market_valid, settings_ok
- `verification_result.py`: `VerificationResult` — trade_allowed, blocker_reasons
- `verification_gate.py`: `evaluate_verification()` — fail-closed gate decision
- `tests/domain/verification/`: 13 new tests

## Architecture
