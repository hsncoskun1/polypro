# Iteration — v0.3.10 Timeframe Mapping Shell

## Scope

Bridges the date-format gap between Polymarket's ISO 8601 end_date field and the system's fixed `Timeframe` enum (`1D`, `1W`, `1M`, `3M`). Prerequisite before real trigger wiring.

## What Changed

New `backend/app/clients/timeframe_mapping.py`:
- `map_end_date_to_timeframe(end_date, reference_date)` maps date strings to `Timeframe`
- Thresholds: ≤1 day→1D, 2–7→1W, 8–30→1M, 31+→3M
- `TimeframeMappingError` on past dates or unparseable strings
- `reference_date` parameter for deterministic testing

## Position in Architecture

```
PolymarketMarketPayload.end_date  (e.g. "2026-05-01")
         │ map_end_date_to_timeframe()   ← v0.3.10
         ▼
      Timeframe.ONE_MONTH               (e.g. "1M")
         │ (used when wiring client to discovery pipeline)
         ▼
     RawMarketItem.timeframe → normalization → registry
```
