# Iteration — v0.4.0 Trading Decision Foundation Pack

## Scope

First trading decision layer. Introduces rule engine, entry rules, rule state model, and entry decision evaluator. No execution, no simulation, no API endpoints. Decision-only domain layer.

## What Changed

- `backend/app/domain/strategy/rule_state.py`: `RuleState` enum (pass/fail/waiting/disabled/locked_by_admin)
- `backend/app/domain/strategy/rule_result.py`: `RuleResult` dataclass
- `backend/app/domain/strategy/entry_decision.py`: `EntryDecision` dataclass
- `backend/app/domain/strategy/rules.py`: 6 entry rule evaluators + `RuleContext`
- `backend/app/domain/strategy/strategy.py`: `evaluate_entry()` + `RuleConfig`
- `backend/tests/domain/strategy/`: 34 new tests across 3 files

## Position in Architecture

