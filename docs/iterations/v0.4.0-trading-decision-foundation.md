# Iteration — v0.4.0 Trading Decision Foundation Pack

## Scope

First trading decision layer. Rule engine, entry rules, rule state model, RuleResult with telemetry fields, entry decision evaluator, locked_by_admin support seam. No execution, no simulation, no API endpoints.

## What Changed

- `rule_state.py`: `RuleState` enum
- `rule_result.py`: `RuleResult` with current_value, threshold_value, distance_to_trigger
- `entry_decision.py`: `EntryDecision` dataclass
- `rules.py`: `RuleContext` + 6 rule evaluators with enabled + locked_by_admin toggles
- `strategy.py`: `evaluate_entry()` + `RuleConfig` with per-rule enable and lock fields
- `tests/domain/strategy/`: 52 tests across 3 files

## Architecture

```
Discovery (v0.3.x)
       │
       ▼
Trading Decision (v0.4.0)
  RuleContext → evaluate_entry(ctx, config) → EntryDecision
                    │
         6 entry rules evaluated
         Any FAIL → trade_allowed=False
         disabled/locked → excluded from blocking
       │
       ▼
Verification Gate (v0.4.3)   ← next seam
       │
       ▼
Simulation Execution (v0.5.x)
```
