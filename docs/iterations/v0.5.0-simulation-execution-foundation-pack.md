# Iteration — v0.5.0 Simulation Execution Foundation Pack

## Scope

Simulation execution foundation. Paper trade entry and exit seam. Duplicate
entry lock. Execution contract that is clean enough to extend to live mode
later without structural conflict. No DB writes, no force sell, no stop loss.

## What Changed

- `execution_request.py`: `ExecutionRequest` — event_key, side, requested_size, simulated_fill_price
- `execution_result.py`: `ExecutionResult` — success, order_id, fill_price, side, size, reason
- `execution_lock.py`: `ExecutionLock` — in-memory duplicate entry guard
- `simulation_executor.py`: `simulate_entry()`, `simulate_exit()` — paper execution
- `tests/domain/execution/`: 22 new tests

## Architecture

```
VerificationResult (v0.4.3)
  trade_allowed = True
        │
        ▼
ExecutionRequest (input)
        │
        ▼
simulate_entry(request, lock)
        │
        ├─ lock.is_locked?   → ExecutionResult(success=False, reason="duplicate_entry_blocked")
        │
        └─ lock.acquire()    → ExecutionResult(success=True, order_id="PAPER-ENTRY-...", ...)
        │
        ▼
[position open]
        │
        ▼
simulate_exit(request, lock)
        │
        └─ lock.release()    → ExecutionResult(success=True, order_id="PAPER-EXIT-...", ...)
        │
        ▼
Position Lifecycle Persistence (v0.5.2)  ← next seam
```
