# Iteration — v0.8.1 Production Client Operational Hardening Pack

## Scope

Operational hardening of the v0.8.0 concrete production client. Timeout policy,
retry policy, exception normalization, correlation/idempotency context, safe logging
with redaction, and response validation. No live applied testing. No network calls.

## What Changed

- `client_timeout_policy.py`: `ClientTimeoutPolicy` — timeout_seconds, retryable_on_timeout
- `client_retry_policy.py`: `ClientRetryPolicy` — max_retries, retry_delay_seconds, retryable_error_codes
- `client_exception_type.py`: `ClientExceptionType` enum — TIMEOUT, CONNECTION_ERROR, INVALID_RESPONSE, AUTH_ERROR, RATE_LIMITED, UNKNOWN
- `normalized_client_exception.py`: `NormalizedClientException` — normalized adapter-safe exception model
- `client_operation_context.py`: `ClientOperationContext` — correlation_id, idempotency_key, timeout_seconds per operation
- `safe_log_payload.py`: `SafeLogPayload` + `redact_payload()` — sensitive field redaction
- `client_response_validator.py`: `validate_submit/cancel/replace/update_response()` — fail-closed response validation
- Tests: 51 new in test_production_client_operational_hardening.py

## Architecture

```
[v0.8.0 — Concrete Production Client]
  │
  ↓ v0.8.1 Operational Hardening Layer
  │
  ClientTimeoutPolicy        ← per-operation timeout config
  ClientRetryPolicy          ← retry classification config
  ClientExceptionType        ← exception taxonomy (6 types)
  NormalizedClientException  ← all exchange errors normalized before adapter propagation
  ClientOperationContext     ← correlation_id + idempotency_key per request lifecycle
  safe_log_payload           ← redact_payload() masks secrets; SafeLogPayload safe for emission
  ClientResponseValidator    ← validate before mapping; fail-closed on missing fields
```

## Fail-Closed Rules

- Unknown exception → terminal_failure=True
- Missing required response fields → validation_passed=False
- terminal_failure=True bypasses status field requirement (valid fail-closed path)
- Secrets never appear in redacted log payloads
