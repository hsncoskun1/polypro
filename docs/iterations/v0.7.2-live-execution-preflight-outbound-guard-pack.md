# Iteration — v0.7.2 Live Execution Preflight + Outbound Guard Pack

## Scope

Fail-closed outbound guard — preflight evaluation before any live outbound action.
No live execution. No live API calls. Guard foundation only.

## What Changed

- `outbound_action_type.py`: `OutboundActionType` enum — LIVE_ORDER_SUBMIT, LIVE_ORDER_CANCEL, LIVE_CLAIM_SUBMIT, OTHER_LIVE_OUTBOUND
- `preflight_context.py`: `PreflightContext` — 10 fields covering mode state, upstream gate results, outbound action type
- `preflight_result.py`: `PreflightResult` — outbound_allowed + blocker_reasons list
- `preflight_evaluator.py`: `evaluate_preflight()` — gate model + all-checks-run (no short-circuit)
- Tests: 26 new in test_preflight.py

## Architecture

```
PreflightContext (input)
  simulation_mode_default, live_mode_requested
  live_mode_enabled, explicit_live_enable
  credentials_complete (from v0.7.1 SecretsResult.is_complete)
  verification_passed, sizing_passed, risk_passed
  outbound_action_type
        │
        ▼
evaluate_preflight()
  Gate 1: simulation_mode_default AND NOT live_mode_requested
          → outbound_allowed=False, ["outbound_not_allowed_in_simulation"]   [stops]
  Gate 2+: all checks run (no short-circuit)
    explicit_live_enable?     → explicit_live_enable_required
    live_mode_enabled?        → live_mode_not_enabled
    credentials_complete?     → live_credentials_incomplete
    verification_passed?      → verification_not_passed
    sizing_passed?            → sizing_not_passed
    risk_passed?              → risk_not_passed
        │
        ▼
PreflightResult (output)
  outbound_allowed = len(blockers) == 0
  blocker_reasons = [all active blockers]
```
