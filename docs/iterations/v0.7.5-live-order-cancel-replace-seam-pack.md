# Iteration — v0.7.5 Live Order Cancel/Replace Seam Pack

## Scope

Cancel and replace seam: status enums, request/result contracts, evaluators.
Cancel and replace are separate lifecycle intents — never collapsed.
No live execution. No network calls. Seam for future exchange client.

## What Changed

- `cancel_status.py`: `CancelStatus` — 8 values (cancel_allowed_not_attempted → cancel_terminal_failure)
- `replace_status.py`: `ReplaceStatus` — 8 values (replace_allowed_not_attempted → replace_terminal_failure)
- `live_cancel_request.py`: `LiveCancelRequest` — order_id, outbound_allowed, preflight_passed
- `live_cancel_result.py`: `LiveCancelResult` — cancel_allowed, cancel_status, reject_reason, retryable, terminal_failure, cancel_attempted_at
- `live_replace_request.py`: `LiveReplaceRequest` — order_id, new_limit_price, new_size, outbound_allowed, preflight_passed
- `live_replace_result.py`: `LiveReplaceResult` — replace_allowed, replace_status, replace_reason, retryable, terminal_failure, replace_attempted_at
- `cancel_replace_evaluator.py`: `evaluate_cancel()` + `evaluate_replace()`
- Tests: 42 new in test_cancel_replace.py

## Architecture

```
evaluate_cancel(LiveCancelRequest)
  Guard priority:
    1. outbound_allowed=False → CANCEL_BLOCKED_OUTBOUND_GUARD
    2. order_id empty         → CANCEL_BLOCKED_PREFLIGHT
    3. preflight_passed=False → CANCEL_BLOCKED_PREFLIGHT
    4. All clear              → CANCEL_READY
        │
        ▼
LiveCancelResult
  cancel_allowed, cancel_status
  reject_reason, retryable, terminal_failure, cancel_attempted_at

evaluate_replace(LiveReplaceRequest)
  Guard priority (same pattern):
    1. outbound_allowed=False → REPLACE_BLOCKED_OUTBOUND_GUARD
    2. order_id empty         → REPLACE_BLOCKED_PREFLIGHT
    3. preflight_passed=False → REPLACE_BLOCKED_PREFLIGHT
    4. All clear              → REPLACE_READY
        │
        ▼
LiveReplaceResult
  replace_allowed, replace_status
  replace_reason, retryable, terminal_failure, replace_attempted_at
  [new_limit_price, new_size carried on request — not collapsed into cancel]
```

## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Cancel and replace are separate intents | Never collapsed — different lifecycle semantics |
| order_id required before preflight | Cannot cancel/replace a non-existent reference |
| Seam only — no network calls | Clean contract for future exchange client |
| Same guard priority pattern as v0.7.3 | Consistent across all live outbound actions |
