# Iteration — v1.1.2 Admin Policy Propagation + Audit Trail Pack

## Scope
Audit trail for admin entitlement changes: domain model, SQLite persistence, API endpoint, frontend panel.

## Decisions
- Audit record is immutable — INSERT only, no UPDATE/DELETE
- snapshot_before captured before save; snapshot_after from saved entitlement
- changed_fields() computed at read time (domain layer, not stored redundantly)
- Endpoint: GET /api/v1/admin/users/{user_id}/audit — admin only, returns newest first
- AuditTrailPanel shown only when a user is selected in AdminPanel
- useAdminAudit hook re-fetches on selectedUser change
