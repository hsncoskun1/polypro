# Iteration — v0.8.5 Frontend/Launcher Surface Wiring + Final App Integration Pack

## Scope

Surface integration layer. Connects v0.6.1 control plane, v0.6.2 admin reporting,
v0.7.x live readiness and v0.8.2–v0.8.4 backend readiness/release gate to user and
admin surface views. New domain: backend/app/domain/surface/.

## What Changed

- `surface/__init__.py`: Package
- `app_integration_state.py`: AppIntegrationState — launcher_blocked + all readiness flags
- `release_gate_ui_state.py`: ReleaseGateUiState — release/gate → Turkish UI labels
- `app_surface_view.py`: AppSurfaceView — user panels, positions, balance, pnl, claim
- `admin_surface_view.py`: AdminSurfaceView — admin panels + safe_stop + alerts
- `surface_label_mapper.py`: TR labels (user + admin), panel lists, blocked messages
- `app_surface_assembler.py`: assemble_user_surface() + assemble_admin_surface()
- Tests: 35 new in test_app_surface_wiring.py

## Architecture

```
AppIntegrationState
  launcher_blocked
  backend_ready / final_backend_ready
  release_ready / live_applied_testing_ready
  │
  ├── assemble_user_surface()  → AppSurfaceView
  │     visible_panels (empty if launcher_blocked)
  │     release_gate_ui_state
  │     user_surface_labels_tr (TR)
  │     blocked_reason_messages (TR)
  │
  └── assemble_admin_surface() → AdminSurfaceView
        visible_panels (full superset)
        admin_surface_labels_tr (TR)
        safe_stop / scheduler / alerts
        blocked_reason_messages (TR)
```

## Key Invariants

- launcher_blocked → user visible_panels=[]
- Admin panels always superset of user panels
- release_ready ≠ live_applied_testing_ready (always separate)
- Secrets never in any surface view
- Turkish labels applied at surface layer only; internal codes stay English
