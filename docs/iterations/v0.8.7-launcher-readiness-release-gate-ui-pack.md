# Iteration — v0.8.7 Launcher + Readiness + Release Gate UI Pack

## Scope

Frontend launcher UI surface + backend /readiness endpoint. First versioned frontend
feature delivering real readiness state to the user. No new backend domain.
No trading logic. No admin/user control plane. Türkçe UI throughout.

## What Changed

**Backend:**
- `backend/app/api/schemas/readiness.py`: ReadinessResponse Pydantic schema (13 fields)
- `backend/app/api/readiness.py`: GET /readiness — static state builder, launcher_blocked logic
- `backend/app/main.py`: readiness_router included

**Frontend:**
- `frontend/src/types/readiness.ts`: ReadinessState TypeScript interface
- `frontend/src/hooks/useReadiness.ts`: polling hook, VITE_BACKEND_URL, 5 s default
- `frontend/src/components/ReadinessCard.tsx`: single status row, informational flag
- `frontend/src/components/BlockedReasonList.tsx`: red-bordered Turkish blocked reasons
- `frontend/src/components/ReleaseGatePanel.tsx`: release_ready + live gate, always separate
- `frontend/src/components/PortInfo.tsx`: port grid + startup commands
- `frontend/src/routes/Launcher.tsx`: full launcher route — loading/error/ready states
- `frontend/src/app/Router.tsx`: "/" → Launcher (was Home)
- `frontend/src/components/Layout.tsx`: nav Türkçeleştirildi (Başlatıcı/Kullanıcı/Yönetici)

**Tests:**
- `backend/tests/api/test_readiness_api.py`: 19 endpoint tests
- `frontend/src/test/launcher.test.tsx`: 27 component + integration tests

## Architecture

```
GET /readiness
    │
    └── _build_readiness_response()
            │
            ├── live_applied_testing_ready = False  (always, never auto)
            ├── launcher_blocked = not live_applied_testing_ready  (always True)
            ├── continue_destination = None  (blocked)
            └── ReadinessResponse (13 fields, no secrets)

useReadiness() ──→ polls /readiness every 5000 ms
    │
    └── Launcher
            ├── loading skeleton
            ├── error state + refresh button
            ├── 5x ReadinessCard (backend_ready, setup_completed,
            │         update_required[inverted], preflight_passed, final_backend_ready)
            ├── ReleaseGatePanel (release_ready | live_applied_testing_ready)
            ├── BlockedReasonList
            ├── blocked CTA or "Uygulamaya Devam Et" button
            └── PortInfo (frontend_port, backend_port, startup commands)
```

## Invariants

- `live_applied_testing_ready` = False — never auto-enabled
- `launcher_blocked` = True — always in current state
- `continue_destination` = None — always in current state
- No secrets in /readiness response
- `release_ready` and `live_applied_testing_ready` always rendered as separate rows
- Nav labels Turkish: Başlatıcı / Kullanıcı / Yönetici
