# Iteration — v0.7.8 Live Exchange Client Adapter Foundation Pack

## Scope

Live exchange client adapter foundation. Abstract interface, request/response contracts,
outcome enum, mock stub. Business logic and orchestrator decoupled from exchange details.
No real network calls. Seam only.

## What Changed

- `adapter_outcome_status.py`: `AdapterOutcomeStatus` — 7 values (submitted → no_update)
- `adapter_submit_request.py`: `AdapterSubmitRequest` — order_id, event_key, market_id, side, size, limit_price
- `adapter_submit_response.py`: `AdapterSubmitResponse` — outcome_status, exchange_order_id, reject_reason, retryable, terminal_failure
- `adapter_cancel_request.py`: `AdapterCancelRequest` — order_id, event_key
- `adapter_cancel_response.py`: `AdapterCancelResponse` — outcome_status, reject_reason, retryable, terminal_failure
- `adapter_replace_request.py`: `AdapterReplaceRequest` — order_id, event_key, new_limit_price, new_size
- `adapter_replace_response.py`: `AdapterReplaceResponse` — outcome_status, new_exchange_order_id, reject_reason, retryable, terminal_failure
- `adapter_order_update.py`: `AdapterOrderUpdate` — outcome_status, filled_size, remaining_size, update_timestamp
- `live_exchange_client.py`: `LiveExchangeClient` ABC — submit_order / cancel_order / replace_order / get_order_update
- `mock_live_exchange_client.py`: `MockLiveExchangeClient` — configurable stub, no network
- Tests: 42 new in test_live_exchange_client_adapter.py

## Architecture

```
LiveExchangeClient (ABC — adapter contract)
  submit_order(AdapterSubmitRequest)  → AdapterSubmitResponse
  cancel_order(AdapterCancelRequest)  → AdapterCancelResponse
  replace_order(AdapterReplaceRequest) → AdapterReplaceResponse
  get_order_update(order_id)          → AdapterOrderUpdate
        │
        ├── MockLiveExchangeClient (stub — configurable outcomes, no network)
        │   Used by tests for all adapter paths
        │
        └── [future] PolymarketLiveExchangeClient (real REST/WS client)
            [future seam → v0.7.9+ real exchange integration]

All adapter responses use AdapterOutcomeStatus (typed enum).
Business logic never receives raw exchange payloads.
```
