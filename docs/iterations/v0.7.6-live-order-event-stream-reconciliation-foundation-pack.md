# Iteration — v0.7.6 Live Order Event Stream + State Reconciliation Foundation Pack

## Scope

Live order event stream model and state reconciliation foundation.
Submission / response / fill / cancel / replace lifecycle unified into one state model.
No websocket/client. No network calls. Seam only.

## What Changed

- `live_order_event_type.py`: `LiveOrderEventType` — 11 values (submitted → failed)
- `live_order_event.py`: `LiveOrderEvent` — event record with order_id, event_type, fields
- `live_order_state.py`: `LiveOrderState` — lifecycle state (filled, cancelled, terminal flags + counters)
- `reconciliation_status.py`: `ReconciliationStatus` — 4 values (reconciled, no_events, conflicting_events, terminal_state)
- `live_order_reconciliation_result.py`: `LiveOrderReconciliationResult` — result contract
- `order_event_reconciler.py`: `reconcile_order_events()` — applies ordered events to produce final state
- Tests: 48 new in test_order_event_reconciler.py

## Architecture

```
reconcile_order_events(order_id, [LiveOrderEvent, ...])
  No events       → NO_EVENTS, final_state=None
  Events applied in order:
    ORDER_SUBMITTED           → state update, non-terminal
    ORDER_ACCEPTED            → state update, non-terminal
    ORDER_PARTIALLY_FILLED    → filled_size / remaining_size update, non-terminal
    ORDER_FILLED              → is_filled=True, is_terminal=True, remaining=0
    ORDER_CANCEL_REQUESTED    → non-terminal
    ORDER_CANCELLED           → is_cancelled=True, is_terminal=True
    ORDER_REPLACE_REQUESTED   → non-terminal
    ORDER_REPLACED            → price/size update, non-terminal
    ORDER_REJECTED            → is_terminal=True
    ORDER_EXPIRED             → is_terminal=True
    ORDER_FAILED              → is_terminal=True
        │
        ▼
LiveOrderReconciliationResult
  order_id, reconciliation_status
  final_state: LiveOrderState
  events_processed, is_terminal, reconciled_at
        │
        ▼
LiveOrderState (latest-known-order-state read model)
  order_id, client_order_id, side
  requested_size, filled_size, remaining_size, limit_price
  current_event_type, is_cancelled, is_filled, is_terminal
  last_event_timestamp, event_count
  [future seam → websocket consumer / persistence layer]
```
