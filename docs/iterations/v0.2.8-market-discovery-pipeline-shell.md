# Iteration Notes — v0.2.8 Market Discovery Pipeline Shell

## Goal

Combine the three discovery layers (shell, source contract, normalization) into a single pipeline entry point. Establish the full source → normalize → discover seam before any real external source is connected.

## Decisions

- **`RawDiscoverySource` (Protocol)**: returns `list[RawMarketItem]` — distinct from `DiscoverySource` (v0.2.6) which returns `list[DiscoveryItem]`. Raw source is for unvalidated external input; existing source contract untouched.
- **`StubRawDiscoverySource`**: wraps a static `list[RawMarketItem]`, mirrors `StubDiscoverySource` pattern from v0.2.6.
- **`run_pipeline()`**: single-line implementation — delegates entirely to `run_discovery_from_raw(source.fetch(), registry)`. No new logic; pipeline is a composition surface only.
- **All existing layers unchanged**: `discovery.py`, `source.py`, `normalize.py` untouched. Pipeline is additive only.
- **File placement**: `pipeline.py` alongside other discovery files in `domain/markets/` — no new top-level module.
