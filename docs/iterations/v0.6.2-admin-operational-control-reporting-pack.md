# Iteration — v0.6.2 Admin Operational Control + Reporting Pack

## Scope

Admin operational control surface and extended reporting foundation.
No frontend, no trading logic, no risk/accounting changes.

## What Changed

- `admin_control.py`: `AdminControl` — safe stop, scheduler, global disable, config seams
- `admin_report_snapshot.py`: `AdminReportSnapshot` — extended admin read model
- `admin_report_assembler.py`: `assemble_admin_report_snapshot()` — pure assembler
- `admin_label_map.py`: `ADMIN_TURKISH_LABELS` — 24-key Turkish label mapping
- Tests: 29 new in test_admin_report.py

## Architecture

```
AdminControl (control surface)
  safe_stop_active, safe_stop_reason,
  scheduler_enabled, global_disable_active,
  config_reload_available, config_reset_available
        │
assemble_admin_report_snapshot()
  + financial data (from accounting)
  + event lists (from risk/execution/claim)
        │
        ▼
AdminReportSnapshot (admin read model)
  operational control state    [from AdminControl]
  financial reporting          [total/available/session/current balance + PnL]
  blocked_trades/rules/risk    [blocked event lists]
  execution_fill_events        [fill log]
  claim_events                 [claim log]
  operational_alerts           [system alerts]
```
