# Iteration — v0.9.0 Settings + Live Configuration UI Pack

## Scope

Settings and live configuration UI surface. Connects to new `GET /settings` endpoint.
Credential status (masked — no plaintext), live config state, trading config.
User/admin panels untouched. No live testing. No new trading logic.

## What Changed

**Backend:**
- `backend/app/api/schemas/settings.py`: SettingsResponse (Pydantic)
- `backend/app/api/settings.py`: GET /settings — credential status flags + live config + trading config
- `backend/app/main.py`: settings_router included

**Frontend:**
- `frontend/src/types/settings.ts`: SettingsState TypeScript types
- `frontend/src/hooks/useSettings.ts`: polling hook (5 s)
- `frontend/src/components/CredentialStatusPanel.tsx`: 7 credential fields — configured/not status
- `frontend/src/components/LiveConfigPanel.tsx`: explicit_live_enable + live_test_gate fields
- `frontend/src/components/TradingConfigPanel.tsx`: client_mode + min_order + event + market
- `frontend/src/components/SettingsGateStatus.tsx`: release_ready + live_applied_testing_ready + blocked reasons
- `frontend/src/routes/Settings.tsx`: Settings page at /settings
- `frontend/src/app/Router.tsx`: /settings route added
- `frontend/src/components/Layout.tsx`: Ayarlar nav link added
- `frontend/src/test/routes.test.tsx`: Settings heading test added
- `frontend/src/test/settings.test.tsx`: 37 tests

## Architecture

```
GET /settings
    │
    └── _build_settings_response()
            ├── api_key_configured = False      (no live sources yet)
            ├── ... (all credentials = False)
            ├── explicit_live_enable = False
            ├── live_test_gate_enabled = False
            ├── live_test_gate_passed = False
            ├── client_mode = simulation_mock
            ├── minimum_order_size = 0.0
            ├── selected_event = ""
            ├── selected_market = ""
            ├── release_ready = True
            ├── live_applied_testing_ready = False  (always)
            └── SettingsResponse (no plaintext values)

useSettings() ──→ polls /settings every 5000 ms
    │
    └── Settings (/settings)
            ├── no credentials banner (when masked_secret_fields empty)
            ├── CredentialStatusPanel (Kimlik Bilgisi Durumu)
            ├── LiveConfigPanel (Canlı Yapılandırma)
            ├── TradingConfigPanel (İşlem Yapılandırması)
            └── SettingsGateStatus (Yayın Durumu)
```

## Invariants

- Credential values never in GET /settings response — only configured boolean flags
- `live_applied_testing_ready` = False — never auto-enabled
- Secrets never shown in UI — only status flags
- User/admin panels untouched in this version
