# Iteration — v0.7.9 Production Client Wiring + Safe Dry-Run Foundation Pack

## Scope

Production client wiring foundation and safe dry-run mode. Four client modes,
adapter factory, client selection evaluator with production gating.
No production exchange client. Seam only.

## What Changed

- `client_mode.py`: `ClientMode` — 4 values (simulation_mock, live_mock, live_dry_run, live_production)
- `client_wiring_context.py`: `ClientWiringContext` — mode flags, production readiness fields
- `client_wiring_result.py`: `ClientWiringResult` — client_ready, real_outbound_allowed, dry_run_active, blocker_reasons
- `dry_run_result.py`: `DryRunResult` — dry_run_action_recorded, real_outbound_performed=False always
- `client_selection_evaluator.py`: `evaluate_client_selection()` — per-mode readiness + blocker evaluation
- `adapter_factory.py`: `resolve_adapter()` — returns correct LiveExchangeClient for mode
- Tests: 44 new in test_production_client_wiring.py

## Architecture

```
evaluate_client_selection(ClientWiringContext)
  SIMULATION_MOCK → ready, no real outbound
  LIVE_MOCK       → ready, no real outbound
  LIVE_DRY_RUN    → ready if wiring_ready, dry_run_active=True, no real outbound
  LIVE_PRODUCTION → all guards must pass: outbound_enabled + client_selected + wiring_ready
        │
        ▼
ClientWiringResult
  client_ready, real_outbound_allowed, dry_run_active, blocker_reasons

resolve_adapter(ctx, mock_client, production_client)
  SIMULATION_MOCK / LIVE_MOCK / LIVE_DRY_RUN → mock adapter (no network)
  LIVE_PRODUCTION                             → production_client (required, raises if None)
        │
        ▼
LiveExchangeClient (v0.7.8 ABC)
  [future seam → real Polymarket REST/WS client]

DryRunResult
  dry_run_action_recorded: bool
  real_outbound_performed: bool = False  ← structural guarantee, never True in dry-run
```
