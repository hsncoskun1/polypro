# Iteration — v0.9.3 Real Exchange Connectivity Audit + Integration Plan Pack

## Hedef

Backend exchange connectivity katmanının gerçek durum tespiti.
Gerçek uygulama ile seam/stub ayrımının netleştirilmesi.
Kritik gap haritasının çıkarılması.
Sonraki entegrasyon sürümlerinin planlanması.

## Kapsam

- Backend domain/live/ tüm dosyaları
- Backend domain/execution/ tüm dosyaları
- Backend domain/accounting/ ilgili dosyalar
- Backend api/ control plane dosyaları
- Kod değişikliği yok

## Taranan Dosyalar

### domain/live/
- `production_exchange_client.py` — tüm `_execute_*` seam'leri
- `live_credentials.py` — credential storage
- `credential_evaluator.py` — presence validation
- `live_execution_orchestrator.py` — state machine
- `order_event_reconciler.py` — fill/cancel reconciliation
- `order_submission_evaluator.py` — submission guards
- `cancel_replace_evaluator.py` — cancel/replace guards
- `adapter_submit_request.py` — submit payload mapping
- `adapter_cancel_request.py` — cancel payload mapping
- `adapter_replace_request.py` — replace payload mapping
- `adapter_order_update.py` — update payload mapping
- `live_order_event.py` — event model
- `secrets_masker.py` — plaintext güvenlik katmanı

### domain/execution/
- `simulation_executor.py` — tam çalışan simulation entry/exit

### domain/accounting/
- `accounting_context.py` — PnL hesaplama, balance fields

### api/
- `control_plane.py` — balance always 0.0

## Sonuç

Simulation mode tam uçtan uca çalışıyor.
Live mode seam seviyesinde donmuş — tüm `_execute_*` hardcoded response döndürüyor.
Kriptografik signing yok. HTTP/WebSocket client yok. Event stream yok.
