# Iteration — v0.3.11 Timeframe Mapping Integration Shell

## Scope

Wires the timeframe mapping layer into the client/payload chain. `end_date` ISO 8601 strings from Polymarket rows are converted to `Timeframe` enum values inside `map_to_raw_payload_item()`. Trigger API endpoint decoupled to accept Timeframe strings directly.

## What Changed

- `backend/app/adapters/external_payload.py`: `map_to_raw_payload_item()` calls `map_end_date_to_timeframe(end_date)`, uses `timeframe.value` in `RawPayloadItem`. `TimeframeMappingError` propagates openly.
- `backend/app/api/discovery.py`: Trigger endpoint builds `RawPayloadItem` directly — API items carry Timeframe enum strings, not ISO dates.
- Tests updated: ISO dates used throughout; new error propagation tests added.

## Position in Architecture

```
PolymarketMarketPayload.end_date  (e.g. "2026-05-01")
         │ map_to_raw_payload_item()   ← now calls map_end_date_to_timeframe()
         ▼
      RawPayloadItem.timeframe = "1M"
         │
         ▼
     normalization → registry
```
