# Iteration — v0.3.11 Timeframe Mapping Integration Shell

## Scope

Wires the timeframe mapping layer into the Polymarket client discovery chain only. `end_date` ISO 8601 strings are converted to `Timeframe` enum values in `discovery_client.py`. The trigger API endpoint and `external_payload.py` contract are unchanged.

## What Changed

- `backend/app/services/discovery_client.py`: calls `map_end_date_to_timeframe(pm.end_date)` before `map_to_raw_payload_item()`. `TimeframeMappingError` propagates openly; `ExternalPayloadMappingError` caught defensively.
- `backend/tests/services/test_discovery_client.py`: ISO date test data; 2 new error propagation tests.

## Position in Architecture

```
PolymarketMarketPayload.end_date  (e.g. "2026-05-01")
         │ map_end_date_to_timeframe()   ← v0.3.11 integration point (discovery_client.py)
         ▼
      PolymarketMarketPayload.end_date = "1M"
         │ map_to_raw_payload_item()
         ▼
      RawPayloadItem.timeframe = "1M"
         │
         ▼
     normalization → registry
```
