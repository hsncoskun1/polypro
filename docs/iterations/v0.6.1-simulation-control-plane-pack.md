# Iteration — v0.6.1 Simulation Control Plane Pack

## Scope

Simulation control plane read model — assembles existing domain data into a single visibility surface.
No new trading logic. No risk/sizing/claim/accounting changes.

## What Changed

- `position_view.py`: `PositionView` — single position read model with all price/move/PnL fields
- `control_plane_snapshot.py`: `ControlPlaneSnapshot` — full read model (positions, session, balance, claim)
- `control_plane_assembler.py`: `assemble_control_plane_snapshot()` — pure assembler, no computation
- `label_map.py`: `TURKISH_LABELS` — 38-key Turkish UI label mapping
- Tests: 29 new in test_control_plane_snapshot.py

## Architecture

```
Domain Evaluators (accounting, claim, risk, sizing)
        │
        ▼
assemble_control_plane_snapshot()
  open_positions=[PositionView, ...],
  closed_positions=[PositionView, ...],
  session_realized_pnl, session_unrealized_pnl, session_total_pnl,
  total_balance, available_balance, current_balance, session_start_balance,
  claim_status, claim_available, claimed_amount, settlement_completed_at
        │
        ▼
ControlPlaneSnapshot (read model)
  open_positions / closed_positions   [always separate]
  session PnL fields                  [three fields, never collapsed]
  balance fields                      [four fields]
  claim/settlement fields             [four fields]

TURKISH_LABELS (dict)
  38 keys → Turkish UI strings
```
