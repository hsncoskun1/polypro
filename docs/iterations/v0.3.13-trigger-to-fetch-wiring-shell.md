# Iteration — v0.3.13 Trigger-to-Fetch Wiring Shell

## Scope

Wires `POST /api/v1/discovery/trigger` to call `run_polymarket_fetch_to_discovery()`. Old stub/manual-payload path removed. Request shape simplified to `source_name`, optional `url`, optional `timeout`. Response contract unchanged.

## What Changed

- `backend/app/api/discovery.py`: trigger endpoint now creates `PolymarketClient` and calls `run_polymarket_fetch_to_discovery()`; manual payload path removed; explicit error handling added.
- `backend/app/api/schemas/discovery.py`: `DiscoveryTriggerRequest` replaced — `RawMarketItemSchema` and `items` removed; `url` and `timeout` added.
- `backend/app/core/config.py`: `POLYMARKET_URL` env config added.
- `backend/tests/api/test_discovery_api.py`: full replacement — 15 old tests removed, 13 new fetch-based tests added.
