## Architecture

```
Layout
  ├── Header (nav: Başlatıcı / Kullanıcı / Yönetici / Ayarlar + HealthBadge)
  ├── Main
  │   └── Route outlet
  │       ├── / → Launcher (own loading/error pattern)
  │       ├── /user → UserPanel → PageShell
  │       ├── /admin → AdminPanel → PageShell
  │       ├── /settings → Settings → PageShell
  │       └── * → NotFound
  └── AppFooter (port info: :5173 / :8000)

PageShell(status)
  ├── loading → animated skeleton (aria-label="Yükleniyor")
  ├── error   → red banner + Yenile button
  └── ready   → children rendered
```

## Invariants

- All PageShell-wrapped routes: same loading/error/content pattern
- NotFound catches all unknown paths gracefully
- AppFooter port guidance visible on all pages
- Secrets not visible on any route
