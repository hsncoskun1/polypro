# Iteration — v1.0.7 Admin Control + Visibility UI Completion Pack

## Scope

Admin control plane UI components, admin user management panel, admin/user
visibility separation. Backend admin API endpoints for user listing, summary
stats, and entitlement management. Frontend hooks, components, and route guards.

## Architecture

```
AdminPanel (route)
  └── requires session_token in localStorage
  ├── useAdminUsers hook
  │     ├── GET /api/v1/admin/users
  │     └── GET /api/v1/admin/summary
  ├── AdminSummaryCards (summary stats)
  ├── AdminUserTable (user list)
  │     └── triggers EntitlementEditor per user
  └── EntitlementEditor
        ├── GET /api/v1/admin/users/{id}/entitlement
        └── PUT /api/v1/admin/users/{id}/entitlement
```

## Admin API Endpoints

| Endpoint | Method | Auth | Description |
|----------|--------|------|-------------|
| /api/v1/admin/users | GET | admin | List all users |
| /api/v1/admin/summary | GET | admin | Aggregate summary stats |
| /api/v1/admin/users/{id}/entitlement | GET | admin | Get entitlement |
| /api/v1/admin/users/{id}/entitlement | PUT | admin | Update entitlement |

## Admin/User Boundary

- All `/api/v1/admin/*` endpoints require `role == admin`
- Non-admin sessions receive 403
- Frontend AdminPanel shows "Not authenticated" if no token present
- RequireAdmin route guard redirects non-admin users
