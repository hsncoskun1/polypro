# Iteration — v0.8.8 User Control Plane UI Pack

## Scope

User control plane UI surface. First real user dashboard. Connects to new
`GET /control-plane` endpoint. No admin panel. No live testing. No new trading logic.

## What Changed

**Backend:**
- `backend/app/api/schemas/control_plane.py`: PositionViewSchema + ControlPlaneResponse (Pydantic)
- `backend/app/api/control_plane.py`: GET /control-plane — empty default state, live_mode_ui_blocked=True
- `backend/app/main.py`: control_plane_router included

**Frontend:**
- `frontend/src/types/controlPlane.ts`: ControlPlaneState + PositionViewData
- `frontend/src/hooks/useControlPlane.ts`: polling hook (5 s)
- `frontend/src/components/PositionTable.tsx`: open/closed position table
- `frontend/src/components/PnlPanel.tsx`: session PnL (realized/unrealized/total)
- `frontend/src/components/BalancePanel.tsx`: 4-field balance grid
- `frontend/src/components/ClaimSummaryCard.tsx`: claim status + Turkish label map
- `frontend/src/components/LiveGateStatus.tsx`: release_ready + live gate + blocked reasons
- `frontend/src/routes/UserPanel.tsx`: replaced placeholder with full control plane UI
- `frontend/src/test/routes.test.tsx`: UserPanel heading updated (Kullanıcı Paneli)
- `frontend/src/test/user-control-plane.test.tsx`: 39 tests

## Architecture

```
GET /control-plane
    │
    └── _build_control_plane_response()
            ├── open_positions = []       (no live source yet)
            ├── closed_positions = []     (no live source yet)
            ├── all PnL/balance = 0.0    (no live accounting yet)
            ├── claim_status = not_claimable_outcome_unknown
            ├── live_applied_testing_ready = False  (always)
            ├── live_mode_ui_blocked = True
            └── ControlPlaneResponse (no secrets)

useControlPlane() ──→ polls /control-plane every 5000 ms
    │
    └── UserPanel
            ├── blocked banner (canlı mod kilitli)
            ├── PositionTable (Açık Pozisyonlar)
            ├── PositionTable (Kapalı Pozisyonlar)
            ├── PnlPanel (Seans K/Z)
            ├── BalancePanel (Bakiye)
            ├── ClaimSummaryCard (Talep / Uzlaşma)
            └── LiveGateStatus (Canlı Mod Durumu)
```

## Invariants

- `live_applied_testing_ready` = False — never auto-enabled
- `live_mode_ui_blocked` = True — always in current state
- Secrets never in /control-plane response
- `release_ready` and `live_applied_testing_ready` always separate rows
- All Turkish UI labels from existing `label_map.py` reference
