# Iteration — v0.3.15 Discovery Trigger Auth Shell

## Scope

Adds static Bearer token auth to `POST /api/v1/discovery/trigger`. Token from env var. No JWT, OAuth, or full user system. Auth is **fail-closed**: missing `TRIGGER_AUTH_TOKEN` returns HTTP 500.

## What Changed

- `backend/app/api/deps.py`: new `verify_trigger_auth` FastAPI dependency (fail-closed)
- `backend/app/api/discovery.py`: `Depends(verify_trigger_auth)` added to trigger endpoint
- `backend/app/core/config.py`: `TRIGGER_AUTH_TOKEN` env config added
- `backend/tests/api/test_discovery_api.py`: 5 new auth tests; all existing tests updated with `Authorization: Bearer` header; `client` fixture sets `TRIGGER_AUTH_TOKEN`; `no_auth_config_client` fixture clears it

## Auth Behaviour

| Condition | Result |
|-----------|--------|
| `TRIGGER_AUTH_TOKEN` not set | HTTP 500 — auth not configured (fail-closed) |
| `TRIGGER_AUTH_TOKEN` set, header missing | HTTP 401 |
| `TRIGGER_AUTH_TOKEN` set, wrong token | HTTP 401 |
| `TRIGGER_AUTH_TOKEN` set, correct Bearer token | Chain runs normally |
