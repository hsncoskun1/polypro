# Iteration — v0.8.9 Admin Reporting + Operational Control UI Pack

## Scope

Admin operational control and reporting UI surface. Connects to new
`GET /admin/control-plane` endpoint. Admin sees broader data than user.
No user panel changes. No live testing. No new trading logic.

## What Changed

**Backend:**
- `backend/app/api/schemas/admin_control_plane.py`: AdminControlPlaneResponse (Pydantic)
- `backend/app/api/admin_control_plane.py`: GET /admin/control-plane — default safe state
- `backend/app/main.py`: admin_control_plane_router included

**Frontend:**
- `frontend/src/types/adminControlPlane.ts`: AdminControlPlaneState
- `frontend/src/hooks/useAdminControlPlane.ts`: polling hook (5 s)
- `frontend/src/components/OperationalControlPanel.tsx`: safe stop / scheduler / global disable / config
- `frontend/src/components/AdminFinancialSummary.tsx`: full balance/PnL grid
- `frontend/src/components/BlockedEventsPanel.tsx`: blocked trades / rules / risk events
- `frontend/src/components/ExecutionReportPanel.tsx`: fill events / claim events / operational alerts
- `frontend/src/components/AdminReleaseGate.tsx`: release gate visibility
- `frontend/src/routes/AdminPanel.tsx`: replaced placeholder with full admin UI
- `frontend/src/test/admin-control-plane.test.tsx`: 45 tests

## Architecture

```
GET /admin/control-plane
    │
    └── _build_admin_control_plane_response()
            ├── safe_stop_active = False
            ├── scheduler_enabled = True
            ├── global_disable_active = False
            ├── config_reload/reset_available = True
            ├── all financial fields = 0.0
            ├── all event lists = []
            ├── release_ready = True
            ├── live_applied_testing_ready = False  (always)
            └── AdminControlPlaneResponse (no secrets)

useAdminControlPlane() ──→ polls /admin/control-plane every 5000 ms
    │
    └── AdminPanel
            ├── global disable banner (when active)
            ├── safe stop banner (when active)
            ├── OperationalControlPanel (Operasyonel Kontrol)
            ├── AdminReleaseGate (Yayın Kapısı)
            ├── AdminFinancialSummary (Finansal Özet)
            ├── BlockedEventsPanel (Bloke Olaylar)
            └── ExecutionReportPanel (Gerçekleşme ve Uyarı Raporu)
```

## Invariants

- `live_applied_testing_ready` = False — never auto-enabled
- Secrets never in /admin/control-plane response
- Admin surface shows broader data than user surface
- User panel untouched in this version
