# Iteration Notes — v0.2.7 Market Discovery Normalization Shell

## Goal

Add a minimal normalization layer between raw source input and the discovery pipeline. Establish a clean "normalize → validate → apply" contract before any real external source integration.

## Decisions

- **`RawMarketItem`**: separate dataclass from `DiscoveryItem` — represents unvalidated external input. Fields are raw strings (may have whitespace or be empty). This makes the boundary explicit.
- **`NormalizationError`**: custom exception for normalization failures. No silent skip — all failures are counted.
- **`normalize_item()`**: strips whitespace, raises `NormalizationError` on empty fields after stripping. Does NOT validate timeframe — that remains in `run_discovery()` via `parse_timeframe()`.
- **`run_discovery_from_raw()`**: normalizes each item, counts failures, merges into final `DiscoverySummary`. `total_seen` reflects all raw items; `skipped_invalid_count` includes both normalization failures and timeframe parse failures.
- **`discovery.py` and `source.py` unchanged**: normalization is additive only. Existing `run_discovery()` and `run_discovery_from_source()` are preserved.
- **File placement**: `normalize.py` alongside `discovery.py` and `source.py` in `domain/markets/` — no new top-level module needed.
