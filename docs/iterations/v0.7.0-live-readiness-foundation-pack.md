# Iteration — v0.7.0 Live Readiness Foundation Pack

## Scope

Live mode protection foundation — mode enum, readiness evaluation contracts, sequential-gate evaluator.
No live execution. No live API wiring. Simulation default unchanged.

## What Changed

- `live_mode.py`: `LiveMode` enum — SIMULATION, LIVE
- `live_readiness_context.py`: `LiveReadinessContext` — 11 fields covering mode intent and all credentials
- `live_readiness_result.py`: `LiveReadinessResult` — live_ready + blocker_reasons list
- `live_readiness_evaluator.py`: `evaluate_live_readiness()` — sequential gates + all-credential-checks-run
- Tests: 23 new in test_live_readiness.py

## Architecture

```
LiveReadinessContext (input)
  simulation_mode_default, live_mode_requested
  live_mode_enabled, explicit_live_enable
  wallet_address_present, private_key_present
  funder_address_present, relayer_api_present
  api_key_present, api_secret_present, api_passphrase_present
        │
        ▼
evaluate_live_readiness()
  Gate 1: simulation_mode_default AND NOT live_mode_requested
          → live_ready=False, blocker_reasons=[]   [normal simulation state]
  Gate 2: NOT explicit_live_enable
          → live_ready=False, ["explicit_live_enable_required"]   [hard stop]
  Gate 3: credential checks [all run, no short-circuit]
    wallet_address_present?    → wallet_address_missing
    api_key_present?           → api_key_missing
    api_secret_present?        → api_secret_missing
    api_passphrase_present?    → api_passphrase_missing
    private_key_present?       → private_key_missing
    funder_address_present?    → funder_address_missing
    relayer_api_present?       → relayer_api_missing
        │
        ▼
LiveReadinessResult (output)
  live_ready = len(blockers) == 0
  blocker_reasons = [all active blockers]
```
