# Iteration — v0.5.1 Exit Policy Foundation Pack

## Scope

Exit decision layer — separate from execution. Stop loss, take profit, and
timeout evaluators. Direction-aware calculation. Pure function, no state mutation.
No force sell, no persistence.

## What Changed

- `exit_context.py`: `ExitContext` — entry_price, current_price, side, thresholds, time_remaining
- `exit_decision.py`: `ExitDecision` — should_exit, exit_reason
- `exit_policy.py`: `evaluate_exit_policy(ctx)` — priority-ordered exit condition evaluation
- `tests/domain/exit/`: 20 new tests

## Architecture

```
ExitContext (input)
        │
        ▼
evaluate_exit_policy()
        │
        ├─ loss_move >= stop_loss_threshold?    → ExitDecision("stop_loss")
        ├─ profit_move >= take_profit_threshold? → ExitDecision("take_profit")
        ├─ time_remaining <= 0?                 → ExitDecision("timeout")
        └─ no condition                         → ExitDecision(should_exit=False)
        │
        ▼
ExitDecision
  should_exit = True/False
  exit_reason = "stop_loss" | "take_profit" | "timeout" | ""
        │
        ▼
simulate_exit() (v0.5.0)  ← applies the decision
```
