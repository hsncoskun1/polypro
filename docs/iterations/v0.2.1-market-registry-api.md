# Iteration Summary — v0.2.1 Market Registry API

## Scope
Connect the v0.2.0 market registry domain layer to a FastAPI HTTP API layer.

## Status
Branch pushed, not yet merged to main.

## What Changed
- `backend/app/api/schemas/` — new Pydantic request/response schemas
- `backend/app/api/markets.py` — new markets router (5 endpoints)
- `backend/app/main.py` — registry lifecycle + markets router registration
- `backend/tests/api/` — 10 new API tests

## Architecture Decisions
- Registry stored in `app.state` (lifespan-managed) — no global singleton
- Request/response models are separate from domain models
- Domain exceptions mapped to appropriate HTTP status codes
- TestClient fixture with context manager ensures fresh registry per test
