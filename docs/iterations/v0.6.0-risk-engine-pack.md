# Iteration — v0.6.0 Risk Engine Pack

## Scope

Hard risk block evaluation — six constraint dimensions, all-or-nothing result.
No frontend, no launcher, no sizing logic changes, no claim logic.

## What Changed

- `risk_context.py`: `RiskContext` — all six constraint dimensions as input
- `risk_result.py`: `RiskResult` — risk_allowed + blocker_reasons list
- `risk_evaluator.py`: `evaluate_risk()` — all checks run, all blockers collected
- Tests: 27 new in test_risk_evaluator.py

## Architecture

```
RiskContext (input)
  daily_loss_limit, current_daily_loss
  daily_trade_cap, current_daily_trade_count
  event_limit, current_event_open_positions
  max_concurrent_positions, current_open_positions
  min_position_size, max_position_size, requested_position_size
        │
        ▼
evaluate_risk()   [all 6 checks run — no short-circuit]
  1. current_daily_loss >= daily_loss_limit     → daily_loss_limit_exceeded
  2. current_daily_trade_count >= daily_trade_cap → daily_trade_cap_exceeded
  3. current_event_open_positions >= event_limit → event_limit_exceeded
  4. current_open_positions >= max_concurrent   → max_concurrent_positions_exceeded
  5. requested_size < min_position_size         → below_min_position_size
  6. requested_size > max_position_size         → above_max_position_size
        │
        ▼
RiskResult (output)
  risk_allowed = len(blockers) == 0
  blocker_reasons = [all active blockers]
```
