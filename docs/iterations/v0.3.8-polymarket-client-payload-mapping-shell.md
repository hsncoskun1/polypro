# Iteration — v0.3.8 Polymarket Client to External Payload Mapping Shell

## Scope

Bridges the gap between `PolymarketClient.fetch()` output (`list[dict]`) and the `PolymarketMarketPayload` external contract. No trigger/service wiring, no new dependencies.

## What Changed

New `backend/app/clients/polymarket_mapping.py`:
- `map_client_rows_to_payloads(rows)` reads `condition_id`, `question`, `end_date` from each dict
- Produces `PolymarketMarketPayload` instances
- Raises `ClientPayloadMappingError` on missing fields — no silent skip
- Whitespace passed through as-is — normalization owned by `map_to_raw_payload_item()` in the next layer

## Position in Architecture

```
[external: Polymarket API]
         │ HTTP GET
         ▼
  PolymarketClient.fetch()       ← v0.3.7
         │ list[dict]
         ▼
  map_client_rows_to_payloads()  ← v0.3.8 (shell only, not yet wired)
         │ list[PolymarketMarketPayload]
         ▼
  map_to_raw_payload_item()      ← v0.3.5 (strips whitespace, validates)
         │ RawPayloadItem
         ▼
  PayloadDiscoveryAdapter / run_discovery_service()
```
